## 범위

제어 틱 계약 1–4 절을 실차 루프로 구현한다. 시험은 **가짜 포트**(실제 `McuLinkHost`·`RealPlantPort` + 가짜 MCU, 장치 없음)로 한다. 4b 설계 11 절이 넘긴 것도 여기서 한다.

- 운영 장치에서는 AUTO ARM·DRIVE 가 나가지 않는다(시험으로 고정). 실 MCU 의 AUTO 는 PR 5 와 S10 선행 조건 뒤에 연다.
- Isaac 은 바꾸지 않는다. 코어를 건드리면 재생 게이트 29/29 와 전체 pytest 를 거친다.

세 단계로 쌓는다.

## 1. 자리

- `src/forklift_core/live/real_loop.py`
  - `RealLoop.cycle(now_ns)`: 한 틱.
  - `RealSession`: Isaac `LiveRuntime` 의 최소판 — `tick_start`(콘솔 → `commands.apply`), `collect_end`/`end_mission`(승강 유지 → `abandon_jobs` → `terminate` → `end_reset` → 결과 기록), `tick_end`(`link.end`).
  - `sim/isaac` 는 가져오지 않는다.
- 시계: 코어 시각 `t = (now_ns − 세션 시작) / 1e9`, `dt = 1/50` 고정(옵션).
  - 벽시계 예약(따라잡지 않음)은 `tools/real_autonomy.py --run`(4c 에서는 가짜 전송기만)이다.
  - 시험은 `cycle()` 을 직접 부르고 가짜 시계를 쓴다.
- 원천(주입):
  - 링크 전송기(`receive(host)` / `transmit(host)` + 프레임마다 `written(kind, seq, t)`).
  - SLAM 링크(응답·추적기).
  - 장애물 층(PR 5 전에는 가짜).
  - 포켓 프레임(PR 7 전에는 None).
  - 콘솔(`Channels`).

## 2. 한 틱 (계약 1 절의 순서)

1. **머리**: 수신 → 새 STATE 마다 한 번씩 다음을 처리한다.
   - `RealOdometry.update`, `SafetySpeed`(표본 시각 기준, 중복은 버림, 공백은 단절), 정지 검출(`slam["stop_now"]`·`still_since` = 새 표본 정지 ∧ `port.outstanding()` 해소)을 갱신한다.
   - 이어 `host.tick` → `permit.tick` → 감시(과속, 주기 초과 두 조건, `SafetyWatch`, 엔코더 유효성)를 본다. trip 이면 `permit.latch` 다.
   - 끝으로 `session.tick_start`(콘솔 명령 → `commands.apply`) 를 부른다.
2. **SLAM·준비**: `core.slam_replies` → 제어 자세 → 준비.
   - 미션이 `accepted` 면 `freeze_submit` 한 번, 그다음 `known_request`.
   - 준비 판정(`auto_ready_refusal(stage="submit")`)이 거부하면 그 사유로 끝낸다.
3. **제어**: Isaac 10628–11131 의 순서를 따른다.
   - 순서: `release_gate` → `job_hold`(`plan_wait_`) → `paused_` → `follow` → `docking_and_stall` → `cusp_and_observe_recovery` → `command` → `arrive` → `job_pending` → `lift_and_timers` → `permission` / `permission_watch` / `blocked_replan` → `paused_tick` / `plan_wait_` / `live_leg`.
   - **S10-A 가 닿지 않는 갈래는 조립하지 않고, 닿으면 래치한다**(`unreachable:<이름>`): 관측 포획(`capture_live`·`observation_live`), `scene_replan.active()`, `loaded_start_wait`, 밑판, 근접 추적, `observe_backoff`.
4. **출력 조립**: `assemble_command` → `cargo.observe` → `observe_motion`(오도메트리) → `safety_state` → `session.tick_end`(중재: `source`·`stop_kind`).
5. **제출**(계약 2 ①):
   - 최종 제출 직전에 STOP·중재 모드·AUTO 허가를 **다시 읽는다**.
   - AUTO 출력이고 `permit.drive_allowed()` 면 `port.command` 로 낸다.
   - 출력이 닫혔는데(계획 대기·스냅숏 설치 대기·preempt 아닌 정지) 허가가 READY/DRIVING 이면 **대기 프레임**(`control_stop` 과 같은 프레임: 바퀴 0·측정 조향·승강 `target` = 측정)을 낸다.
   - STOP·DISARM·lease 상실·링크 상실·측정 무효·포트 거부는 `permit.latch`(즉시 DISARM) 다.
   - S10 은 `take_s10_stop()` → `port.control_stop` → `permit.control_stop(seq)` 다.
   - 출력 직전 예외는 정지 경로로 간다.
6. **송신과 다음 틱으로 넘김**(계약 1.6):
   - `transmit` 이 프레임마다 `permit.written` 을 알린다.
   - `state["command_speed"]`·`state["applied_command"]`·`slam["applied_speed"]` 에는 MCU 가 확인한 출력(그 seq 를 알린 STATE)만 넣는다.
   - 단, 송신됐거나 큐·부분 송신에 있고 만료 전인 **움직일 수 있는 미확인 DRIVE** 가 있으면 그 속도를 `command_speed` 에 넣는다(방향 허가·정지 완료 보류; 반대 방향이 섞이면 0 이 아닌 쪽이 남는다).
   - 확인 출력은 틱 머리에서 갱신한다.

## 3. 감시 기준 (잠정, Jetson 실측 뒤 확정)

- 주기 초과는 두 조건이다: 연속 3 회 > 30 ms, 또는 한 주기 > 60 ms. 단계별 시간(머리·제어·출력·제출)을 기록한다.
- 과속: `SafetySpeed.bound_mps` 가 S10 상한의 1.5 배를 넘으면 trip 이다.
- `SafetyWatch`: 텔레옵 다리와 같은 설정이다(`config/real/safety_watch.yaml`). 입력 `armed` 는 `permit.armed` 다.

## 4. 세션 수명주기 (4c-3)

- 미션 끝(`commands` 가 FINAL)은 `collect_end` 가 수거한다. 순서:
  1. 승강을 측정 위치로 유지한다(코어 `ms.lift_command`).
  2. `abandon_jobs`.
  3. `terminate`/`note_end`.
  4. `end_reset`(현장 복구 열기 포함).
  5. 결과 기록.
- S10 끝은 배달 판정 없이 한 번 수거한다. `end_reset` 이 연 현장 복구가 후속 AUTO·텔레옵을 막는다. 제어 정지 프레임은 그 잠금이 버리지 않는다.
- SLAM 이 무효면 hold 해제를 미룬다(`end_release_due`). 해제 시도(`release_gate`)는 SLAM 이 유효할 때만 부른다.
- 모든 미션 끝은 `permit.mission_ended` 를 부른다(4b 13 절).

## 5. 시험 (계약 4 절 + 4b 11 절)

- 정상 틱의 최종 `command()` 1 회와 seq.
- 중재와 제출 사이에 온 STOP → 옛 후보 제출 0 회. 큐에 들어간 뒤 STOP → 폐기.
- 출력 직전 예외 → 정지 경로.
- 미확인 DRIVE:
  - 확인된 0 → 전진 DRIVE 송신(완전 송신, 첫 바이트 뒤 `EAGAIN` 의 부분 송신 두 경우) → 확인 지연 중 반대 방향 요청이나 취소 → 방향 전환·정지 완료가 보류됨.
  - STOP·거부 뒤 다음 틱이 옛 후보를 적용된 출력으로 읽지 않음.
- 분기: 계약 3 ③ 표의 각 행(S10-A 에 있는 것)과 겹침. 닿지 않는 갈래는 래치.
- 순서: SLAM 응답 → 제어 자세 → 준비 요청 → `release_gate`·`job_hold`.
- S10 가짜 포트 제한 운용:
  - 알려진 시작 → 접근 → (가짜 깊이) → 삽입 → 들림 확인 → 확인 틱과 다음 틱 모두 최종 바퀴 0.
  - 제어 정지 seq 확인 → DISARM → `recovery_required/s10_lifted` 한 번 → AUTO·텔레옵이 잠김.
  - 승강 유지 DRIVE 거절 → 즉시 DISARM. 확인 STATE 유실 → 100 ms 뒤 DISARM.
- lease 상실 → STOPPED·래치, 재무장 전 재개 없음.
- 운영 장치 차단: 가짜가 아닌 전송기로 AUTO ARM·DRIVE 가 나가지 않음.
- AST 부분 순서(4c-3): 두 루프에 같은 검사를 돌린다(계약 4 절의 ①–④).
- 틱 훅 표(4c-3): S10-A 경로 전체를 `fail_closed_hooks` 로 돌려 읽힌 이름이 표와 같음.
