# 연속 포켓 관측과 삽입 제어

사용자 요청: 계획서의 다음 단계 진행과 실제 실행 영상 확인.

## 설계와 범위

기존 RGB-D 인식 기반 정렬 접근 이후, 매번 새 깊이 영상으로 포켓 쌍을
갱신하며 저속 삽입한다. 로봇 위치와 장애물 지도는 현재처럼 시뮬레이터
입력이고 팔레트 정답은 배치·평가·접촉 중단 검사에만 사용한다.
근접 화각과 차체 자체 가림을 먼저 조사한다. 기존 카메라는 삽입 끝에서
팔레트 앞면보다 전방에 놓이므로 그대로 추적에 사용할 수 없다.
카메라 변경은 합성 배치이며 실물 D435i 장착 보정으로 간주하지 않는다.

물리 시각을 멈추고 렌더하는 관측 경계를 유지하되, 정지한 차량만이 아니라
이동 중인 차량의 순간 자세에서도 영상과 TF를 짝짓는다. 관측 사이에만
물리를 진행한다. 영상 60fps와 실시간 인식 처리 성능은 구분한다.

새 관측의 좌우 대응·시각·프레임·출처·연속성을 검증하고, 관측 소실이나
오래된 관측·급격한 목표 변화 때 즉시 0 속도를 명령한다. 재획득은 정지
상태에서 연속된 유효 관측을 확인한 뒤에만 허용한다. 마지막 목표만으로
삽입을 계속하거나 정답 좌표로 대체하지 않는다.

## 작업 순서

1. 카메라 후보의 화각·차체 가림·실제 깊이 검출 가능 거리를 조사한다.
2. 이동 중 순간 RGB-D 관측 API와 시각/자세 불변 경계 회귀시험을 추가한다.
3. 유효 관측에만 반응하는 포켓 추적·삽입 제어와 소실/지연/오검출 시험을 추가한다.
4. Isaac에서 정렬 접근과 연결하고 정상 삽입 및 관측 소실 정지를 실행한다.
5. 60fps 영상, 원시 관측, 제어·정지 거리·간격 평가를 저장한다.
6. 실제 확인된 범위만 계획서와 검증 기록에 반영한다.

## 완료 판정

끝까지 관측을 유지한 물리 삽입과 관측 소실 시 물리 정지를 각각 확인한다.
불가능한 카메라 배치나 검출 실패는 결과로 남기며 성공으로 대체하지 않는다.
전체 운반·승강·LiDAR/SLAM 및 실물 검증은 이 단계의 완료 범위가 아니다.

## 실행 기록

- 기존 기능 브랜치의 미커밋 접근 구현을 그대로 이어서 작업한다. 연결 정보 파일은 작업 대상에서 제외한다.
- 독립 작업: 로컬 ray 기반 근접 관측 조사와 Isaac 물리/렌더 검증을 분리한다.
- 판단: 기본 인식의 평균 면 추정을 유지하고 중앙값 보정은 최초 관측 대상과 대응되는 근접 단계에만 적용한다. 선반 오인식이 늘어나는 진단 결과를 보존한다.
- 구현: 순간 RGB-D 취득, 관측 유효성/대응 검사, 재획득 조건, 실제 제동 확인과 원시 로그를 연결했다.
- 사용자 추가 요청: 일반 접근 목표를 0.6m/s로 올리고 진입 직전 0.055m/s로 감속한다. 실제 최고 0.602/0.598m/s와 0.594m/s 관측 소실 후 58.57mm 정지를 확인했다.
- 검증: 1058개 통과, 4개 건너뜀. 변경 코드 lint/format 및 추가 코드 리뷰 통과.
- 남은 기준: 근접 화각·가림 때문에 전체 삽입 완료는 미충족이다. 성공처럼 처리하지 않고 영상과 실패/정지 결과를 남긴다.
