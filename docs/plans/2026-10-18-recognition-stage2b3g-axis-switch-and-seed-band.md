# 팔레트 인식 단계 2B-3g — T11 같은 면의 축 판독 전환, 근소 실패 확장, 시퀀스 seed 대역

> **실행 방식:** 이 세션에서 직접 구현, Codex 검토를 수렴까지 받고 진행한다.

**Goal:** 2B-3f 판정(`docs/validation/2026-10-18-recognition-stage2b3f-suppress-duplicates.md`, `evaluation_g`)에서 남은 실패 — 대상 중복 프레임(V1 4, V2 2), 사례별 한 시퀀스 미달(V1 S2·S3, V2 S6), V2 3.0–3.5 m yaw 개선 — 를 없앤다. 사용자 지시(2026-10-18): "seed 넓히고 계속 진행." 평가 seed 대역을 새로 열고 같은 고정 기준(2B-3 계획 §7)으로 한 번 판정한다.

**Spec:** 2B-3b(가설 전환), 2B-3c(중복 의심·선택 우선), 2B-3d(근소 실패), 2B-3e(그림자), 2B-3f(숨김 탄생). 아래만 바꾼다.

## 진단 (다 쓴 `evaluation_g` + 보정 집합 — 개발 자료)

`evaluation_g` 는 2B-3f 판정에 한 번 썼으므로 이제 개발 자료다(2B-3b 가 2B-3 평가 집합을 진단에 쓴 것과 같은 처리). 판정은 새 대역에서만 한다. 진단 스크립트 `diag_residual.py`, 여유 측정 `probe_margin_g.py`, 효과 측정 `probe_2b3g*.py`(세션 scratchpad).

**T11 의 x↔y 는 면 전환이 아니다.** 2B-3 계획은 "다른 진입면(정사각 T11 의 90°)은 관문을 통과하지 못해 새 트랙"이라 했고, 그 경우는 yaw 가 90° 달라 자세 관문이 막는다. 위 세 건은 같은 면·같은 포켓 쌍을 x 가설(아래판이 삽입축으로 보임)과 y 가설로 번갈아 읽은 **판독 모호성**이다 — 정사각 T11 x0.6 은 두 축의 개구 배치가 같아(3 블록 × 80 mm, 개구 210 mm) 아래판 증거만 축을 가른다.

## 바꾸는 것

1. **축 판독 전환은 한 트랙 — 같은 자리에서만:** 알려진 형상 판독은 트랙의 첫 알려진 가설과 **형상**(키의 `:` 앞, `t11_06`·`epal6`)이 같아야 하고, 트랙이 **가장 최근에 받은 알려진 판독의 키**와 축이 다르면(축 전환) 두 포켓이 트랙의 마지막 관측 대비 **두 축 모두 0.2 m 안**에서 움직였을 때만 판독 관문을 통과한다. 첫 가설과만 비교하면 x → y → x 의 마지막 전환이 제한을 건너뛰므로(Codex) 최근 키와 비교하고, 그 키는 이력 밖에 두어 융합 창·충돌 재설정에 지워지지 않게 한다(배치 구간 검사는 그대로, 0.2 m 는 근소 실패의 포켓 위치 상한과 같은 값·같은 계산). 자세 관문만으로는 정지 트랙의 넓은 관문에 다른 팔레트의 다른 축 판독이 들어온다(Codex 반례: 앞뒤 T11 간격 710 mm, 0.8 s 정지 선택 트랙, 관측 간 이동 510 mm ≤ 관문 586 mm → 선택 트랙이 B 로 부활). 개발 자료의 같은 대상 축 전환은 포켓 이동 0.059–0.175 m 였다. EPAL 6 ↔ T11 은 계속 비호환. 90° 면 전환은 자세 관문이 막는다. 출력 후보는 지금처럼 최신 판독의 가설을 그대로 낸다.
2. **yaw 근소 실패 상한 30° → 40°**(`near_miss_yaw_cap_rad`). 배율 1.5 × 는 그대로. 근거: 같은 대상의 근소 실패 yaw 32.1°(진리 없는 판독)·35.0°·35.2°, 모두 ≤ 1.39 ×.
3. **계열을 건너는 받침 비교:** 새 판독과 선택 트랙의 마지막 관측의 계열(알려진·비규격)이 다르면 근소 실패의 받침은 배율(2.5 ×) 없이 **45 mm 상한만** 본다. 같은 계열이면 지금 그대로.
4. **시퀀스 seed 대역:** `recognition_scenes.SEED_BANDS` 에 `sequence = 2,000,000`(폭 1,000,000 — `eval_pool` 1,000,000–1,999,999 와 `train` 5,000,000– 사이의 빈 구간)을 더하고, 새 시퀀스 대역은 그 안에 100,000 간격으로 둔다: `evaluation_h = 2,000,000`. 기존 대역(`calibration` … `evaluation_g`)은 재현을 위해 그대로 둔다. `recipe_for` 는 칸 번호 `0 ≤ index < CELL_STRIDE` 이고 seed 가 `eval_pool` 또는 `sequence` 대역 안일 때만 받는다(풀 검사만으로는 음수·1,000 이상 index 가 다른 대역·다른 칸 seed 와 겹친다 — Codex). `population_problem` 은 `1 ≤ per_cell ≤ CELL_STRIDE` 를 요구한다. 장면 목록(1,000,000–1,001,019)·`train` 과 겹치지 않음을 시험으로 고정한다.
5. 보정표·W 는 그대로(보정 집합으로 다시 돌려 행·W 동일 확인). 평가는 `evaluation_h`(13 칸 × 8 × 3 종류 = 312 기록, UBAI 8 CPU 샤드) 한 번.

## 개발 자료에서의 효과 (판정 아님)

| 설정 | 보정 V1 (중복 / 유지) | `evaluation_g` V1 | `evaluation_g` V2 |
|---|---|---|---|
| 2B-3f | 0 / 0.918 | 중복 4 · 사례별 4 구간 미달 | 중복 2 · 사례별 3 구간 · 3.0–3.5 m yaw |
| 1 만 | 0 / 0.925 | 중복 5 · S3 1 구간 | 중복 2 |
| 2 만 | 0 / 0.918 | 2B-3f 와 같음 | 사례별 3 구간 · 3.0–3.5 m yaw |
| 1 + 2 | 0 / 0.933 | 중복 3 | **전 기준 통과** |
| **1 + 2 + 3** | 0 / 0.933 | **전 기준 통과**(유지 0.996) | **전 기준 통과**(유지 0.996) |

정체 오류는 모든 설정·변형(V1–V5)에서 0. 기록 변형 V3 유지 0.942, V4 중복 2(2B-3f 5), V5 0.996. 2판의 0.2 m 축 전환 제한을 더한 1 + 2 + 3 도 V1·V2 전 기준 통과·유지 0.996·정체 오류 0 으로 같고, 기록 변형 V4 중복만 5(2B-3f 와 같음)로 돌아온다(`probe_2b3g_v2.py`). 3판 구현(최근 키 비교) 그대로 돌리면 V1·V2 전 기준 통과·유지 0.996·정체 오류 0, 보정 V1 유지 0.933·중복 0, V4 중복 2(`probe_impl.py`). **`evaluation_g` 로 고른 값이므로 이 표는 판정이 아니다** — 판정은 `evaluation_h` 가 한다.

## 이웃 여유 (원자료 재계산)

보정 집합 + `evaluation_g` 의 V1·V2 에서 활성 선택 트랙 기준 포켓 0.2 m 안에 든 판독 5,366 건 중 진리가 대상과 다른 것 975 건:

- 받침 차이 < 45 mm 인 것은 9 건이고 **모두 대상 팔레트 자신의 진리 없는 판독**(라벨 `(k, None, None)`, 쌍 미대응)이다. 진짜 이웃(다른 인스턴스 또는 다른 면·쌍)은 한 건도 없다.
- 나머지 966 건은 S4 적층의 위·아래 층(받침 81–285 mm) — 45 mm 상한이 가른다. 비규격 최소 높이는 0.010 + 0.045 + 0.012 + 0.012 = 0.079 m(`recognition_scenes.py` 생성 범위)라 층 간 받침 차이는 79 mm 이상이다.
- 그래서 2·3 의 확장 구간(yaw 30–40°, 계열 건넘 받침 ≤ 45 mm)에 진짜 이웃은 이 자료에 없다. 진리 없는 판독이 숨겨지는 것은 의도한 동작이다(그 판독이 새 트랙이 되어 대상 관측을 가져간 것이 `s1_epal6_1983006` 의 손실).

## 작업

1. `candidate_tracking.py`: `_reading_fits` 형상 단위 호환, `near_miss_yaw_cap_rad` 기본 40°, `_near_miss` 계열 건넘 받침. 시험(먼저 실패 확인):
   - 같은 면 T11 x → y(자세 통과, 포켓 이동 ≤ 0.2 m)는 같은 트랙 — 활성·정지 트랙 모두, 2B-3b 의 "T11 x → y 새 트랙" 시험은 **90° 면 전환**(yaw 90°)으로 바꿔 새 트랙 유지, EPAL 6 ↔ T11 은 새 트랙;
   - x → y → x·y → x → y 로 첫 축에 돌아오는 전환도 0.2 m 제한(Codex 2판 반례: 보정표, 3.30 m 에서 x·y 를 읽은 선택 트랙에 0.8 s 뒤 3.81 m 의 다른 팔레트가 x 로) — 같은 축만 읽은 대조군은 자세 관문으로 부활; 비규격 판독을 거친 전환, W = 0(이력이 최신 판독뿐)에서도 제한 유지;
   - Codex 반례 수치 그대로(앞뒤 T11 710 mm, 0.8 s 정지 선택, 이동 510 mm): 다른 축 판독은 새 트랙, 부활 0; 같은 축이면 지금처럼 관문이 판단(변경 없음 확인); 이동 0.2 m 정각은 통과, 0.21 m 는 거부;
   - 축 전환 뒤에도 배치 구간이 막는 판독은 막힘;
   - yaw 35°/25° (1.4 ×) 는 근소 실패, 41° 는 아님(배율 안이어도), 40° 정각 포함;
   - 계열 건넘 받침 44 mm(관문 7 mm)는 근소 실패, 46 mm 는 아님, 같은 계열 44 mm(5.9 ×)는 아님;
   - 켠 상태 정체 불변(2B-3f 시험 묶음)이 그대로 통과.
2. `recognition_scenes.py`·`recognition_sequences.py`·`evaluate_track_sequences.py`: `sequence` 대역, `evaluation_h`, `recipe_for` 의 index·대역 검사, `population_problem` 의 per_cell 범위. 시험: 모든 시퀀스 대역이 자기 풀 안에 13 × 1,000 을 담음, 장면 목록·`train` 과 서로 겹치지 않음, index −1·1,000 거부, `evaluation_h` index −17,000(= `evaluation_g` 시작 seed) 거부, per_cell 0·1,001 거부.
3. 보정 재실행 확인 → `evaluation_h` 생성(UBAI) → 평가 한 번 → 기록 `docs/validation/2026-10-18-recognition-stage2b3g-axis-switch.md`.

## 위험

- **개발 자료에 맞춘 값:** 40° 와 계열 건넘 규칙은 각각 3 건·1 건에서 나왔다. 새 대역이 판정하지만, 같은 자리에서 30–40° 돌아 보이는 진짜 다른 팔레트(이 자료에 없음)는 활성 선택 트랙 근처에서 숨겨질 수 있다.
- **축 판독이 바뀌는 출력:** 트랙 출력의 가설 키가 프레임마다 x·y 로 바뀔 수 있다. 하류(진입 축 판단)는 최신 판독 키를 그대로 받는다 — 지금도 최신 판독의 키를 내므로 형식은 같지만, 한 트랙 안에서 축이 바뀌는 것은 새 동작이다.
- **진리 없는 판독:** 숨김 확장으로 대상 팔레트 위 진리 없는 판독이 그림자로 더 많이 숨겨진다 — 선택 트랙이 그 판독을 받는 경로(`sel=other`)는 바뀌지 않는다.
- **계열 건넘 적층(합성 반례, Codex P3):** 실제 층 간격 90 mm 에서 아래층 알려진 받침이 46 mm, 위층 비규격 받침이 90 mm 로 읽히면 차이 44 mm 라 위층이 숨겨진다(1.75 m 받침 관문 7.5 mm, 기존 2.5 × 한계 18.7 mm 면 보였다). 그런 오판이 렌더에서 나는지는 확인하지 않았고, 생성기의 S7 비규격은 단일 인스턴스라 새 대역도 비규격 적층을 검증하지 않는다. 시험으로 이 경로의 현재 동작을 고정하고 잔여 위험으로 둔다.
- **실제 창고(agy):** ① T11 의 축은 아래판 방향이 다르므로 진입 판단에서 의미가 있다 — 트랙은 축을 확정하지 않고 최신 판독 키를 낼 뿐이며, 진입 축 결정은 근접 판독이 해야 한다. ② 30–45° 로 비스듬히 놓인 이웃: 숨김은 두 포켓이 모두 0.2 m 안일 때만이라 앞면이 겹치는 자리(적층 제외)에서만 일어난다 — 적층은 받침 45 mm 상한이 가른다. ③ 선택 트랙이 원거리에서 잘못 잡히면 넓어진 숨김이 진짜 대상을 숨긴다 — 이 평가의 선택은 정답(oracle)이라 검증하지 않는다. ④ 휘거나 처진 팔레트·마스트 흔들림으로 받침 판독이 45 mm 넘게 어긋나면 숨김 대신 보이는 중복이 된다(지금과 같은 실패 방향). ⑤ 45 mm 에 가까운 얇은 팔레트 적층은 생성 범위(최소 79 mm) 밖이다.
- 남은 대역: `sequence` 대역은 100,000 간격으로 10 개를 담는다.

## 검토 기록

### 1판 (2026-10-18) → 2판
