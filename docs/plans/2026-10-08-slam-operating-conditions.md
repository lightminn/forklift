**운용 방식:** 현황 문서가 정한 순서대로 **"시험장 지도를 한 번 만들어 저장하고, 이후 주행은 그 지도에서 위치만 추정한다"** 를 먼저 검증한다(Claude 해석 —
현황 문서의 "먼저" 를 따른 것이고, 사용자가 다른 방식을 고르면 바뀐다).

## 측정한 사실 (2026-10-08, ws1 `EXP = artifacts/20261007T_visual_slam`)

- 기록 `nominal_seed0–5`(0.5 m/s)와 `fast_seed0–3`(1.0 m/s)은 같은 조사 루프(116 m)다. **seed 0–3 은 두 속도의 `scene.usda` SHA-256 이 같고**(배치 동일) 출발
  base 위치가 둘 다 (−5.34, 0.00) m 다. 그래서 **nominal 기록으로 만든 지도에서 fast 기록을 위치 추정**하면 같은 장면·다른 속도·다른 스캔 위치의 재주행이 된다.
- 같은 기록의 slam_toolbox 지도 작성 재생(L-ST, 가정 잡음) 시작 정렬 ATE: nominal seed 1/2/3 = 5.0/5.2/5.2 cm, fast seed 1/2/3 = 8.8/8.2/8.5 cm
  ([비교 기록](../validation/2026-10-07-visual-slam-and-fusion.md) §6·§7.5).
- 이미지 `forklift/ros2-dev:jazzy` 의 slam_toolbox 2.8.5 에 `localization_slam_toolbox_node` 와 `localization_launch.py`(lifecycle)가 있다. AMCL·nav2 는 없다.
- 기록 차체는 `dls08_provisional` 이다. 5순위 계획 v10 은 판정을 실측 차체(`dls08_measured`)로 옮겼다 — **이 계획의 O1–O5 는 기존 기록을 쓰므로 잠정 차체이고,
  실측 차체 판정은 새 기록이 필요한 O6 에서 한다.** LiDAR 장착((−0.12, 0, 1.05) m)은 두 차체가 같다.

## 설계

### 지도와 좌표

- **O1 지도 저장.** `nominal_seedN` 을 지금의 L-ST 재생 그대로(`slam_toolbox_isaac_replay.yaml`, 잡음 seed N) 지도 작성으로 돌리고, 가방이 끝나면
  `/slam_toolbox/serialize_map` 으로 pose graph(`.posegraph`·`.data`)를 저장한다. 점유 지도(`map.pgm`)는 `slam_recorder` 가 이미 쓴다.
- **지도 좌표계 = 지도 기록의 출발 base 자세.** slam_toolbox 의 map 은 첫 스캔의 odom 원점에서 시작하고, 재생 odom 은 기록 출발에서 단위 변환이다. 그래서
  위치 추정 결과는 **정렬 없이** `T_world_map = 지도 기록 출발 base 자세` 로 정답과 비교한다. 이것이 운용에서 실제로 쓰는 값이다(시작 정렬 ATE 가 아니다).
- 위치 추정 파라미터는 지도 작성 설정과 **같은 정합 매개변수**에 `mode: localization`·`map_file_name`·`map_start_pose` 만 바꾼다. 튜닝은 seed 0 에서만 한다.

### 시험

- **O2 저장 지도 위치 추정(출발 자세 알려짐).** 지도 `nominal_seedN` 위에서 `fast_seedN`·`nominal_seedN` 을 **다른 잡음 실현(seed 100+N)** 으로 재생한다. 비교
  대상은 같은 재생을 빈 지도에서 지도 작성한 L-ST(같은 잡음 seed)의 정렬 없는 오차다.
- **O3 재기동.** 가방을 도중 시각 t₀ ∈ {60, 120, 180} s 부터 재생하고(`--start-offset`), 초기 자세를 정답에 오차 {0, (0.25 m, 0.05 rad), (0.5 m, 0.10 rad),
  (1.0 m, 0.20 rad)} 를 더해 준다. 위치 오차 방향은 차체 기준 45° 로 고정한다. 수렴 = 재생 시작 10 s 안에 0.10 m·0.05 rad 아래로 들어가 끝까지 0.15 m 아래에 머무름.
  **판정이 아니라 한계 측정이다** — 수렴하는 최대 초기 오차를 운용 한계로 적는다.
- **O4 위치 소실.** (a) 위치 추정 중 LiDAR 20 s 끊김 × 3(`sensor_conditions` `lidar_blackout`, 비교 기록과 같은 창) — 끊김 동안 오차와 복귀 뒤 수렴 시간.
  (b) 납치: 초기 오차 (2.0 m, 0.5 rad) 로 시작 — slam_toolbox 는 근처 탐색만 하므로 수렴하지 않을 것으로 본다(가설). 이때 **잘못된 추정을 스스로 알아채는지**를 본다.
- **O5 위치 건강 감시와 전역 재위치(`forklift_core`, ROS·시뮬레이터 무관).**
  - 건강 점수: 스캔 끝점 중 저장 지도의 점유 칸에서 d 안에 드는 비율(거리 변환). 연속 k 스캔이 문턱 아래면 "소실".
  - 전역 재위치: 저장 지도 자유 칸 전체에서 우도장(likelihood field) 정합으로 (x, y, yaw) 를 거칠게 → 세밀하게 찾는다. 창고는 반복 구조라 **두 번째 후보(1 m 넘게
    떨어진)와 점수 차가 작으면 거부**한다 — 틀린 자세를 내는 것보다 거부가 낫다.
  - d·k·문턱·거부 비율은 seed 0(nominal 지도 + fast 기록)에서만 정하고 고정한 뒤 seed 1–3 을 한 번 평가한다.
  - 연결: 재위치 결과를 O3 의 재기동 초기 자세로 넣어 slam_toolbox 가 수렴하는지 본다(오프라인에서 재초기화와 같다).
- **O6 지도 변경·실측 차체(Isaac, ws1, 이 계획 범위의 마지막).** 지도 기록과 같은 seed 에서 저장 팔레트 일부를 빼거나 옮긴 배치를 `dls08_measured` 로 새로 기록하고
  O2·O4·O5 를 다시 돌린다. 변경 비율과 배치 생성 방식은 O5 뒤에 이 계획을 고쳐 정한다.
- **후진·회전**은 조사 루프에 없다. 운반 임무 기록(후진 포함)을 저장 지도에서 위치 추정하는 것은 O6 이후로 미룬다.

## 단계와 판정 (결과 보기 전 고정)

기준은 **Claude 잠정안**이다(사용자 확인 전). 운용 기준은 10/04 폐루프의 제어 입력 오차 규모(raw RMSE 7.6 cm·최대 16.9 cm, S1 seed 0)를 넘지 않는 것이다.

| 단계 | 대상 | 통과 |
|---|---|---|
| O1 | seed 0–3 지도 | 4 개 모두 직렬화 성공, 다시 읽기 성공 |
| O2 | seed 1–3 × {nominal, fast} = 6 재생 | 6/6 에서 자세 있는 스캔 ≥ 99 %, 정렬 없는 RMSE ≤ 같은 재생 L-ST 의 정렬 없는 RMSE, 최대 ≤ 0.15 m |
| O3 | seed 1–3 × t₀ 3 × 초기 오차 4 | 판정 없음 — 초기 오차별 수렴 비율을 적는다. 오차 0 은 9/9 수렴해야 한다(아니면 O3 설정 결함) |
| O4a | seed 1–3 | 3/3 에서 끊김마다 LiDAR 복귀 뒤 5 s 안에 0.10 m 아래 |
| O4b·O5 | seed 1–3 의 fast 기록 스캔, 기록당 등간격 100 개 | 재위치: **틀린 수용 0/300**, 맞음(0.15 m·0.05 rad 안) ≥ 80 %. 건강 감시: O4b 납치 3/3 을 30 s 안에 소실로 판정, O2 6 재생에서 헛경보 0 |

## 이 계획이 말하지 않는 것

- 실물 RPLIDAR·엔코더 잡음·지연(가정값), 실물 창고의 지도 변화 빈도.
- 움직이는 장애물, 장애물 지도·주행 허가(5순위, `feat/p5-p0a`).
- 다층·3D 지도, 여러 지도 이어 붙이기, 장기(lifelong) 지도 갱신 — slam_toolbox lifelong 모드는 이번에 평가하지 않는다.
- O1–O5 의 잠정 차체 결과를 실측 차체 판정으로 세지 않는다.

## 자체 검토

- **같은 장면 가정은 해시로 확인했다**(seed 0–3, 위 측정한 사실). seed 4·5 는 fast 기록이 없어 O2 의 교차 속도 비교에서 뺀다.
- **위치 추정을 같은 기록으로 하면 정답을 외운 셈이다.** 그래서 O2 는 다른 속도(fast) 기록과, 같은 속도라도 다른 잡음 실현으로 재생한다. nominal 재주행은 같은 경로·같은 렌더라
  fast 보다 쉬운 조건임을 결과에 함께 적는다.
- **"정렬 없는 오차" 의 기준점**은 두 기록의 출발 base 자세가 같다는 사실에 기댄다(측정 0.00 m 차). 출발이 다른 기록을 쓰는 단계(O6)에서는 지도 기록 출발 자세로
  명시 변환한다.
- 판정 숫자(99 %, 0.15 m, 80 %, 30 s)는 Claude 가 고른 값이다. 사용자 확인 전 잠정이며, 결과를 본 뒤 바꾸지 않는다 — 바꾸려면 새 판으로 적는다.
