# 상품 기반 지게차 모델 구현 계획

**목표:** 상품 사진과 DLS08 카탈로그를 근거로 수정 가능한 URDF/MJCF 잠정 모델을 만들고 로컬에서 검사한다.

**설계:** [모델 설계](../design/2026-09-10-product-forklift-model.md). Python 생성기가 YAML → 공통 부품 트리 → 두 모델 형식으로 변환한다. ROS 및 기존 코어의 구조 전환은 수행하지 않는다.

**의존성:** Python >= 3.10, PyYAML; 검사·미리보기에는 MuJoCo, NumPy, Pillow, pytest. 코어 필수 의존성은 유지한다.

- [x] 판매페이지 원본 이미지와 제조사 치수 도면을 읽고 URL·해시를 저장한다.
- [x] 실제 생성 명령과 생성된 모델을 검사하는 시험을 작성한다. 생성기가 없는 상태의 실패를 확인한다.
- [x] 주요 수치 YAML, 생성기, URDF/MJCF/장면을 구현한다. 전체 크기 1.46 × 0.63 × 1.01m를 검사하고 변경된 YAML도 적용되는지 검사한다.
- [x] MuJoCo 관절 변환으로 승강 z 방향, 두 포크의 간격 보존, 앞/뒤 조향 선택을 검사한다. 외부 충돌 형상을 포함한 모델로 중력 아래 3초 정지 시험을 수행한다.
- [x] 다각도 PNG와 관절 자세 미리보기를 생성해 직접 확인한다. 셸·코드·모델·결과 문서를 함께 검사한다.
- [x] 기존 64개 코어 시험과 새 시뮬레이션 시험을 실행하고 README·두 지침 미러·검증 기록을 갱신한다. 커밋·push는 수행하지 않는다.

검증 완료: [81개 시험과 렌더 확인 기록](../validation/2026-09-10-product-forklift-model.md).
