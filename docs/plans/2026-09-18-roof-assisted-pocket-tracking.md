# 팔레트 윗판 관측을 이용한 근접 삽입 구현 계획

> 실행 방식: superpowers:subagent-driven-development. 기존 기능 브랜치의
> 미커밋 작업을 보존하고 독립적인 관측 검증과 Isaac 실행을 나눠 진행한다.

**목표:** 앞면 포켓이 화각을 벗어난 뒤에도 새 깊이 형상으로 포켓 위치를
갱신해 실제 삽입을 완료하고, 삽입 중 관측 소실 시 정지를 확인한다.

**구조:** 최초 인식은 기존 포켓 검출기다. 알려진 빈 EPAL 6 팔레트에 대해
근접 영상에 남아 있는 윗판 뒤쪽 모서리와 판재 사이 홈을 측정해 상대 자세를
갱신한다. 앞면 검출과 겹치는 구간에서 일치 여부를 확인한 뒤 관측을 인계한다.
예상 위치는 검색 범위와 대상 대응에만 쓰며 현재 형상 증거 없이 출력하지 않는다.

**기술:** NumPy 코어, 기존 RGB-D 계약과 EPAL 6 형상 설정, Isaac Sim 물리 주행.
관측 방식은 직접 보이는 포켓 검출과 모델에 의한 포켓 위치 추정을 구분해 기록한다.

## 제약

- 코어는 ROS·Isaac SDK에 의존하지 않는다. 모델 규격은 알려진 형상 정보이며 실측 보정이 아니다.
- 팔레트 정답은 배치·사후 평가·독립적인 접촉 중단 검사에만 사용한다.
- 바퀴로 주행한다. 자세 직접 배치는 별도의 정적 관측 진단에서만 사용한다.
- 일반 접근 0.6m/s와 진입 전 0.055m/s 감속, 새 관측·정지 조건을 유지한다.
- 가려짐·NaN·홈/모서리 부족·모델 불일치·대상 대응 실패는 관측 실패다.
- 물리를 고정한 렌더/추론과 시뮬레이션 60fps 영상은 실시간 처리율과 구분한다.
- 원본 실패·중간 결과를 덮어쓰지 않는다. 커밋·push는 이번 요청에 포함되지 않는다.

## 작업

- [x] 합성 ray 및 실제 Isaac 깊이로 앞면 거리 1.3→0.59m의 뒤쪽 모서리·홈 관측 가능성을 확인한다. 예상 위치를 의도적으로 틀리게 줘도 측정이 실제 위치로 수렴하는지 확인한다.
- [x] `src/forklift_core/perception/`에 현재 깊이에 근거한 추적과 진단을 추가한다. 정상·소실·NaN·단순 판재·잘못된 참조·부분 가림을 먼저 시험한다.
- [x] 기존 `run_pocket_insertion.py`에 앞면 검출과의 일치 확인 및 추적 인계를 연결한다. 원시 깊이, 방식, 증거 수, 오차·상태를 저장한다.
- [x] HPC에서 실제 삽입과 삽입 중 깊이 소실을 시험하고 접촉 후보·정지 거리·실제 최종 자세를 평가한다.
- [x] 회귀·리뷰·영상 확인을 마친 후 검증 기록과 `계획.md`를 갱신한다.

## 판정 기준

정상 시도는 삽입 완료 시점까지 새 관측이 있고 실제 최종 위치·방향과 3차원
간격 검사를 통과해야 한다. 소실 시도는 0 명령과 병진·각속도 정지를 실제로
측정한다. 윗판 추정으로 포켓을 직접 관측했다고 주장하지 않으며, 빈 팔레트의
알려진 판재 배치가 바뀌거나 적재물이 윗판을 가리는 조건은 별도 검증 대상이다.

## 진행 기록

- 판단: 추가 센서나 실물 구동기 가정을 만들기 전에 기존 카메라에 남는 깊이 증거를 시험한다.
- 독립 작업: 로컬 추적 가능성 진단과 전체 차체를 포함한 Isaac 정적 캡처를 병행한다.

- 결과: seed 0·17 실제 삽입 완료, seed 0 삽입 중 깊이 소실 뒤 0.682mm 이동 후 정지. 전체 1,097개 통과·4개 건너뜀. 상세 근거와 조건부 간격 해석은 [검증 기록](../validation/2026-09-18-roof-assisted-insertion.md)에 있다.
