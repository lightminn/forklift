# 팔레트 인식 단계 2B-3e — 선택 트랙이 중복 의심 트랙을 흡수

> **실행 방식:** 이 세션에서 직접 구현, Codex 검토를 수렴까지 받고 진행한다.

**Goal:** 2B-3d 평가(`docs/validation/2026-10-18-recognition-stage2b3d-near-miss-duplicates.md`)에서 곡선 접근(V2)은 **대상 중복 트랙** 기준만 남았고, 보정 집합에서 중복 프레임은 22 → 28 로 늘었다 — 중복 의심 트랙이 표시만 되고 남아 선택 트랙과 함께 대상을 가리켰기 때문이다. 사용자 결정(2026-10-18)대로 선택 트랙이 관측을 받을 때 자기 중복 의심 트랙을 흡수(삭제)하고, **새 평가 집합**에서 같은 고정 기준으로 다시 판정한다.

**사용자 결정 (2026-10-18):** 흡수 규칙.

**Spec:** 2B-3c 계획 §1(중복 의심·선택 우선), 2B-3d 계획(근소 실패). 아래만 바꾼다.

## 바꾸는 것

- **흡수:** 한 프레임에서 선택 트랙이 관측 O 를 수락하면(우선 단계든 원래 단계든), 선택 트랙의 중복 의심 트랙(`duplicate_of == 선택 id`) 중 **yaw·받침 근소 실패로 태어났고**(2B-3d, 판독이 선택 트랙과 같다) **그 프레임 매칭 전 상태에서 O 가 관문(판독·자세)을 통과하던** 트랙을 지운다. **판독 관문에서 갈라져 태어난 중복 의심 트랙(T11 다른 면, 비규격 배치·계열)은 지우지 않는다** — 그 트랙은 선택 트랙이 거부하는 판독을 갖고 있어, 지우면 나중에 대상이 그 판독으로 읽힐 때 받을 트랙이 없어지고 그 관측이 이웃에 넘어간다(Codex 반례: 2B-3d 에서는 보류, 판독 갈라짐까지 지우면 앞쪽 T11 이웃이 수락 — 정체 오류). **그 프레임에 보류된 중복 의심 트랙도 지우지 않는다**(다른 관측을 받을 가능성이 남았다). 그리고 **흡수 시점에 중복 의심 트랙이 받아들일 판독은 선택 트랙도 받아들여야** 한다 — 선택 트랙에 확정된 알려진 형상 가설이 있고 중복도 같은 가설이어야 하고(가설이 없는 트랙은 어떤 알려진 판독도 받으므로 더 넓고 — Codex 3판, 가설이 아직 없는 선택 트랙은 나중에 가설을 배울 수 있다 — Codex 브랜치 리뷰 둘; 비규격 선택 트랙은 흡수하지 않는다), 포켓마다 누적 배치 구간이 선택 트랙의 구간 안에 있어야 한다. 근소 실패로 태어난 트랙도 이후 다른 판독(T11)을 받거나 배치 구간이 갈라질 수 있기 때문이다(Codex 2판 반례 둘). 보정 집합에서 이 조건의 비용은 대상 중복 프레임 19 → 21(2B-3d 28). 지운 트랙의 이력은 선택 트랙에 합치지 않는다 — 판독이 다른 관측(T11 면 전환, 배치가 갈라진 비규격 판독)을 섞으면 포켓 구간 교집합과 융합이 오염되므로, 선택 트랙은 자기 관측만 유지한다.
- **흡수하지 않는 경우:** O 에 맞지 않는 중복 의심 트랙(예: T11 다른 면 판독만 받는 트랙)은 남긴다 — 같은 팔레트의 다른 면일 수도 있고, 지금 같은 관측을 두고 겨루지 않으므로 지울 근거가 약하다. 선택이 없거나 선택 트랙이 관측을 받지 못한 프레임에는 흡수하지 않는다. **같은 프레임에 다른 관측을 받은 중복 의심 트랙도 흡수하지 않는다** — 그 트랙은 다른 무언가를 추적 중이고, 지우면 그 관측이 버려진다(구현 중 2B-3c 그래프 시험 S–O1, D–O1, D–O2 에서 발견).
- 흡수 횟수를 `FrameReport.absorbed` 로 내고 평가에서 센다.
- **남는 중복 프레임(평가 전 명시):** 중복 의심 트랙이 태어나는 프레임과, 선택 트랙이 다음 관측을 받기 전까지는 두 트랙이 함께 대상을 가리킨다 — 흡수는 그 다음 프레임부터 효과가 있다. 중복 0 기준은 여전히 넘지 못할 수 있다.
- 새 평가 대역 `evaluation_e` = 1,950,000 + 칸 × 1,000 + i(312 기록 — eval_pool 대역이 2,000,000 에서 끝나므로), 판정 한 번, 기준은 2B-3 계획 §7 그대로. 보정표·W 는 그대로(보정 집합으로 다시 돌려 확인, W 가 달라지면 같은 규칙의 새 W 를 평가 전에 커밋).

## 작업

1. `candidate_tracking.py`: 매칭 전 O 와 각 중복 의심 트랙의 관문 통과를 기록하고, 선택 트랙이 O 를 수락한 뒤 그 트랙들을 지운다. 시험(먼저 실패 확인):
   - 선택 트랙과 중복 의심 트랙이 모두 맞는 관측 → 선택 트랙이 받고 중복 의심 트랙은 사라짐(`absorbed == 1`)
   - O 에 맞지 않는 중복 의심 트랙은 남음
   - 진짜 이웃(중복 의심 아님)은 같은 관측에 맞아도 지워지지 않음
   - 선택이 없거나 선택 트랙이 관측을 받지 못하면 흡수 없음
   - 선택 트랙이 원래 단계(우선권 없이)에서 O 를 받아도 흡수
   - 흡수된 트랙 id 는 다시 쓰이지 않고 `select` 할 수 없음
   - 선택 트랙의 이력·포켓 구간은 흡수 전과 같음(합치지 않음)
2. 보정 재실행 확인, `evaluation_e` 평가 한 번, 보정 집합에서 중복 프레임 변화 진단, 기록 `docs/validation/2026-10-18-recognition-stage2b3e-absorb-duplicates.md`.

## 위험

- 근소 실패 표시가 틀린 경우(진짜 이웃이 중복으로 표시 — 2B-3d 의 활성·0.2 m·판독 통과 조건이 제한한다) 흡수는 그 이웃 트랙을 지운다. 지워진 이웃의 다음 관측은 새 트랙이 되거나, 그 관측이 선택 트랙의 관문에 들면 선택 트랙이 받을 수 있다 — 후자는 정체 오류다. 판독 갈라짐 중복을 흡수 대상에서 뺀 것은 이 경로 중 판독 정보 손실로 생기는 것을 막지만, 근소 실패 쪽의 오표시는 막지 못한다.
- 판독 갈라짐 중복(T11 면 전환 등)은 남으므로 그쪽 중복 프레임은 줄지 않는다.
- **흡수의 본질적 대가 — 잔여 실패로 수용(평가 전 명시):** 트랙을 지우면 그 트랙의 판독 가설뿐 아니라 **자세 가설**(위치·yaw·받침의 마지막 관측)도 사라진다. 판독이 포함 관계여도, 이후 대상 관측이 선택 트랙의 자세 관문은 넘고 지운 중복 트랙의 관문에는 들었을 경우 그 관측이 이웃의 관문에 들면, 2B-3d 에서는 중복 트랙과 이웃 사이에서 보류였던 것을 이웃이 받는다 — **정체 오류**다(Codex 4판 반례, 같은 EPAL 가설·같은 배치 구간에서 받침만 다른 경우). 이 경로를 막으려면 지운 트랙의 자세 가설을 모호성 판단용으로 보존해야 하는데, 그것은 흡수를 하지 않는 것과 같아 사용자 결정(흡수)과 맞지 않는다. 그래서 이 경로는 잔여 실패로 받아들이고, 동작을 시험으로 고정하며(`test_known_residual_absorbing_a_duplicate_also_removes_its_pose_hypothesis`), 평가에서 정체 오류로 센다.
- 흡수된 트랙이 실제로는 다른 대상(사용자가 나중에 고를 팔레트)이었다면 그 트랙의 이력이 사라진다 — 원거리 정보 손실이다.

## 검토 기록

### 1판 (2026-10-18)

- **Codex**(P1 0 · P2 1 · P3 1): ① 관문 통과는 동등관계가 아니라, 판독이 다른 중복 의심 트랙을 지우면 이후 그 판독의 대상 관측을 이웃이 가져감(T11 이웃 반례 — 2B-3d 보류 → 2B-3e 이웃 수락) → 근소 실패 중복만 흡수, 반례 회귀 시험, 위험 절 정정. ② 보류된 중복 의심의 처리 → 보류된 트랙은 흡수 안 함, 시험.
- **agy 독립 검토**(Gemini 3.8 Flash High, 도구 없음): T11 면 전환 중복은 흡수되지 않아 V2 중복이 남을 수 있음·탄생 프레임 중복·원래 단계에서 중복이 먼저 받는 경우·매칭 비용 왜곡·하류의 트랙 소멸 → 위험·잔여로 기록(선택 트랙은 지워지지 않으므로 하류가 참조하는 id 는 남는다).
- **구현 중 발견(Claude):** 같은 프레임에 다른 관측을 받은 중복 의심 트랙까지 지우면 그 관측이 버려짐(2B-3c 그래프 시험) → 예외 추가.

### 2판 (2026-10-18)

- **Codex 재검토**(P1 0 · P2 1): 탄생 분류(near_miss)는 흡수 시점의 판독 동등성을 보장하지 않음 — 이후 T11 판독을 받은 중복, 배치 구간이 갈라진 중복을 지우면 판독 정보가 사라져 이웃이 대상 관측을 받음 → 흡수 시점 포함 조건(`_reading_contains`), 두 경로 시험.

### 3판 (2026-10-18)

- **Codex 재검토**(P1 0 · P2 1): 가설이 없는 중복을 포함으로 인정한 방향이 거꾸로(가설 없음 = 어떤 알려진 판독도 받음) — 실제 보정표 반례에서 흡수 뒤 이웃이 대상 T11 판독을 받음 → 선택 트랙에 가설이 있으면 중복도 같은 가설을 가져야 함, 방향별 시험. 보정 집합 중복 프레임은 그대로 21.

### 4판 (2026-10-18)

- **Codex 재검토**(P1 0 · P2 1): 판독 포함은 자세 관문을 포함하지 않아, 정확한 중복을 지워도 정체 오류가 생김(받침 반례) → 흡수의 본질적 대가로 판단해 **잔여 실패로 명시**하고 시험으로 고정(Codex 가 제시한 두 선택지 중 '잔여 실패로 수용').

### 5판 (2026-10-18) — 흡수 = 그림자

- **Codex 브랜치 리뷰**(P2, 세 차례): 흡수 시점의 포함 조건을 아무리 더해도(가설 일치 → 가설 확정 → 배치 구간 포함) 이후 선택 트랙이 가설을 배우거나 구간이 좁아지면 지운 중복이 받았을 판독을 거부해, 그 판독이 이웃에 넘어갔다(반례 셋). 트랙을 지우는 한 그 가설(판독·배치·자세)이 사라지는 것이 근본 원인이다.
- **변경:** 흡수한 중복은 지우지 않고 **그림자**로 둔다 — 출력·선택·수명 목록에서 빠지고 관측을 받지 않으며 매칭에도 들어가지 않지만, 원래 수명(keep_s)까지 **선택 트랙이 아닌 트랙이 받으려는 관측이 그림자의 관문에 들면 보류**시키고, 그림자에만 맞는 관측은 새 트랙을 만들지 않는다(Codex 권고: 삭제한 가설을 keep_s 까지 모호성 판단용으로 보존). 그래서 포함 조건(`_reading_contains`)은 뺐고, 앞서 잔여 실패로 받아들였던 자세 가설 손실도 막힌다(그 시험은 이제 보류를 기대한다).
- 처음 구현은 그림자를 매칭 그래프에 넣어 선택 트랙과도 겨루게 했다 — 선택 트랙을 막을 이유가 없으므로 매칭에서 빼고 사후 거부로 옮겼다. 보정 집합(평가기 기준) 대상 중복 프레임: 2B-3d 28 → 지우기+포함 조건 21 → **그림자 19**, 정체 오류 0.
- 그림자는 추적기 동작을 바꾸므로 `evaluation_e` 를 다시 쓰지 않고 새 대역 `evaluation_f`(1,970,000)에서 판정한다.

### 6판 (2026-10-18)

- **Codex 브랜치 리뷰**(P2): 그림자 거부를 매칭 뒤에 적용하면 거부된 짝 때문에 다른 관측의 배정이 확정된다(그림자 D–O1, A–O1/O2, B–O2 에서 B 가 O2 를 받음) → 그림자에 맞는 관측에 대해 선택 트랙 외 트랙의 간선을 **매칭 전에** 빼고 유일성을 판정. 거부된 관측은 누구도 받지 않고 새 트랙도 만들지 않는다. 반례 시험 추가. 보정 집합 중복 프레임 19, 정체 오류 0(변화 없음).

### 7판 (2026-10-18)

- **Codex 브랜치 리뷰**(P2): 매칭 전에 그림자에 맞는 관측의 비선택 간선을 빼면 실제 이웃과의 경쟁까지 사라져, 이웃의 관측이 정지한 선택 트랙으로 넘어간다(활성·정지 두 경우) → 그림자를 **경쟁에는 참여하지만 받지 않는 트랙**으로 활성 단계 매칭에 넣는다. 유일 매칭에서 그림자가 따낸 관측은 보류, 선택 트랙이 맞는 관측에는 그림자 간선을 두지 않는다(선택 트랙은 자기 흡수 중복에 지지 않음). 그 밖의 경쟁은 2B-3b 그대로. 반례 시험 둘(정지 선택 + 활성 이웃 → 이웃이 받음, 활성 선택 + 이웃 → 보류).

### 8판 (2026-10-18)

- **Codex 브랜치 리뷰**(P2): 그림자 경쟁 면제가 소유자를 확인하지 않아, 선택을 이웃으로 바꾸면 이전 대상의 그림자도 면제돼 대상 관측이 이웃에게 넘어감 → 면제는 그림자를 흡수한 선택 트랙에만, 선택 전환 시험.

### 9판 (2026-10-18)

- **Codex 브랜치 리뷰**(P2): 소유자가 여러 관측에 맞을 때 그 전부에서 그림자 간선을 빼면 대안 매칭이 사라져 틀린 배정이 확정됨(S→{O1,O2}, E→{O2,O3}, D→{O1,O2,O3}) → 면제는 소유자가 맞는 관측이 **하나일 때만**, 그래프 시험(관문을 연결표로 대체).

### 10판 (2026-10-18)

- **Codex 브랜치 리뷰**(P2): 정지한 소유자에게도 면제를 주면 활성 단계의 대안 매칭이 사라짐(정지 S→O1, 활성 E→{O1,O2}, 그림자 D→{O1,O2}) → 면제는 소유자가 **활성**일 때만. 이를 넣자 앞의 시험(정지 S·활성 E·그림자 D 가 모두 맞는 관측은 E 가 받음, 2B-3d 와 같음)과 충돌 — 그림자를 늘 활성 단계에 넣은 것이 원인이어서, 그림자는 **자기 나이에 맞는 단계**(그 중복 트랙이 살아 있었다면 들어갔을 단계)에서 경쟁하게 했다. 두 시험 모두 통과, 보정 집합 중복 19·정체 오류 0.

### 11판 (2026-10-18) — 그림자 = 숨겨진 중복 트랙

- **Codex 브랜치 리뷰**(P2): 그림자가 매칭에서 따낸 관측을 버리면 나이가 갱신되지 않아 정지 단계로 밀리고, 다음 대상 관측이 이웃에게 넘어감(2B-3d 에서는 중복 트랙이 받아 활성 유지) → 그림자는 **숨겨진 중복 트랙**이다: 관측을 받고 나이·수명도 보통 트랙처럼 갱신하므로 2B-3d 에서 그 중복이 만들던 모호성을 그대로 유지하고, 출력·선택·중복 집계에서만 빠진다. 선택 트랙의 자기 그림자 면제(활성 소유자, 단일 관측)는 그대로. 연속 프레임 반례 시험.
