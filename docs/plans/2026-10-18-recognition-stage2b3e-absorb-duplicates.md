# 팔레트 인식 단계 2B-3e — 선택 트랙이 중복 의심 트랙을 흡수

> **실행 방식:** 이 세션에서 직접 구현, Codex 검토를 수렴까지 받고 진행한다.

**Goal:** 2B-3d 평가(`docs/validation/2026-10-18-recognition-stage2b3d-near-miss-duplicates.md`)에서 곡선 접근(V2)은 **대상 중복 트랙** 기준만 남았고, 보정 집합에서 중복 프레임은 22 → 28 로 늘었다 — 중복 의심 트랙이 표시만 되고 남아 선택 트랙과 함께 대상을 가리켰기 때문이다. 사용자 결정(2026-10-18)대로 선택 트랙이 관측을 받을 때 자기 중복 의심 트랙을 흡수(삭제)하고, **새 평가 집합**에서 같은 고정 기준으로 다시 판정한다.

**사용자 결정 (2026-10-18):** 흡수 규칙.

**Spec:** 2B-3c 계획 §1(중복 의심·선택 우선), 2B-3d 계획(근소 실패). 아래만 바꾼다.

## 바꾸는 것

- **흡수:** 한 프레임에서 선택 트랙이 관측 O 를 수락하면(우선 단계든 원래 단계든), 선택 트랙의 중복 의심 트랙(`duplicate_of == 선택 id`) 중 **yaw·받침 근소 실패로 태어났고**(2B-3d, 판독이 선택 트랙과 같다) **그 프레임 매칭 전 상태에서 O 가 관문(판독·자세)을 통과하던** 트랙을 지운다. **판독 관문에서 갈라져 태어난 중복 의심 트랙(T11 다른 면, 비규격 배치·계열)은 지우지 않는다** — 그 트랙은 선택 트랙이 거부하는 판독을 갖고 있어, 지우면 나중에 대상이 그 판독으로 읽힐 때 받을 트랙이 없어지고 그 관측이 이웃에 넘어간다(Codex 반례: 2B-3d 에서는 보류, 판독 갈라짐까지 지우면 앞쪽 T11 이웃이 수락 — 정체 오류). **그 프레임에 보류된 중복 의심 트랙도 지우지 않는다**(다른 관측을 받을 가능성이 남았다). 그리고 **흡수 시점에 중복 의심 트랙이 받아들일 판독은 선택 트랙도 받아들여야** 한다 — 선택 트랙에 알려진 형상 가설이 있으면 중복 의심 트랙도 같은 가설을 가져야 하고(가설이 없는 트랙은 어떤 알려진 판독도 받으므로 더 넓다 — Codex 3판), 포켓마다 누적 배치 구간이 선택 트랙의 구간 안에 있어야 한다. 근소 실패로 태어난 트랙도 이후 다른 판독(T11)을 받거나 배치 구간이 갈라질 수 있기 때문이다(Codex 2판 반례 둘). 보정 집합에서 이 조건의 비용은 대상 중복 프레임 19 → 21(2B-3d 28). 지운 트랙의 이력은 선택 트랙에 합치지 않는다 — 판독이 다른 관측(T11 면 전환, 배치가 갈라진 비규격 판독)을 섞으면 포켓 구간 교집합과 융합이 오염되므로, 선택 트랙은 자기 관측만 유지한다.
- **흡수하지 않는 경우:** O 에 맞지 않는 중복 의심 트랙(예: T11 다른 면 판독만 받는 트랙)은 남긴다 — 같은 팔레트의 다른 면일 수도 있고, 지금 같은 관측을 두고 겨루지 않으므로 지울 근거가 약하다. 선택이 없거나 선택 트랙이 관측을 받지 못한 프레임에는 흡수하지 않는다. **같은 프레임에 다른 관측을 받은 중복 의심 트랙도 흡수하지 않는다** — 그 트랙은 다른 무언가를 추적 중이고, 지우면 그 관측이 버려진다(구현 중 2B-3c 그래프 시험 S–O1, D–O1, D–O2 에서 발견).
- 흡수 횟수를 `FrameReport.absorbed` 로 내고 평가에서 센다.
- **남는 중복 프레임(평가 전 명시):** 중복 의심 트랙이 태어나는 프레임과, 선택 트랙이 다음 관측을 받기 전까지는 두 트랙이 함께 대상을 가리킨다 — 흡수는 그 다음 프레임부터 효과가 있다. 중복 0 기준은 여전히 넘지 못할 수 있다.
- 새 평가 대역 `evaluation_e` = 1,950,000 + 칸 × 1,000 + i(312 기록 — eval_pool 대역이 2,000,000 에서 끝나므로), 판정 한 번, 기준은 2B-3 계획 §7 그대로. 보정표·W 는 그대로(보정 집합으로 다시 돌려 확인, W 가 달라지면 같은 규칙의 새 W 를 평가 전에 커밋).

## 작업

1. `candidate_tracking.py`: 매칭 전 O 와 각 중복 의심 트랙의 관문 통과를 기록하고, 선택 트랙이 O 를 수락한 뒤 그 트랙들을 지운다. 시험(먼저 실패 확인):
   - 선택 트랙과 중복 의심 트랙이 모두 맞는 관측 → 선택 트랙이 받고 중복 의심 트랙은 사라짐(`absorbed == 1`)
   - O 에 맞지 않는 중복 의심 트랙은 남음
   - 진짜 이웃(중복 의심 아님)은 같은 관측에 맞아도 지워지지 않음
   - 선택이 없거나 선택 트랙이 관측을 받지 못하면 흡수 없음
   - 선택 트랙이 원래 단계(우선권 없이)에서 O 를 받아도 흡수
   - 흡수된 트랙 id 는 다시 쓰이지 않고 `select` 할 수 없음
   - 선택 트랙의 이력·포켓 구간은 흡수 전과 같음(합치지 않음)
2. 보정 재실행 확인, `evaluation_e` 평가 한 번, 보정 집합에서 중복 프레임 변화 진단, 기록 `docs/validation/2026-10-18-recognition-stage2b3e-absorb-duplicates.md`.

## 위험

- 근소 실패 표시가 틀린 경우(진짜 이웃이 중복으로 표시 — 2B-3d 의 활성·0.2 m·판독 통과 조건이 제한한다) 흡수는 그 이웃 트랙을 지운다. 지워진 이웃의 다음 관측은 새 트랙이 되거나, 그 관측이 선택 트랙의 관문에 들면 선택 트랙이 받을 수 있다 — 후자는 정체 오류다. 판독 갈라짐 중복을 흡수 대상에서 뺀 것은 이 경로 중 판독 정보 손실로 생기는 것을 막지만, 근소 실패 쪽의 오표시는 막지 못한다.
- 판독 갈라짐 중복(T11 면 전환 등)은 남으므로 그쪽 중복 프레임은 줄지 않는다.
- 흡수된 트랙이 실제로는 다른 대상(사용자가 나중에 고를 팔레트)이었다면 그 트랙의 이력이 사라진다 — 원거리 정보 손실이다.

## 검토 기록

### 1판 (2026-10-18)

- **Codex**(P1 0 · P2 1 · P3 1): ① 관문 통과는 동등관계가 아니라, 판독이 다른 중복 의심 트랙을 지우면 이후 그 판독의 대상 관측을 이웃이 가져감(T11 이웃 반례 — 2B-3d 보류 → 2B-3e 이웃 수락) → 근소 실패 중복만 흡수, 반례 회귀 시험, 위험 절 정정. ② 보류된 중복 의심의 처리 → 보류된 트랙은 흡수 안 함, 시험.
- **agy 독립 검토**(Gemini 3.8 Flash High, 도구 없음): T11 면 전환 중복은 흡수되지 않아 V2 중복이 남을 수 있음·탄생 프레임 중복·원래 단계에서 중복이 먼저 받는 경우·매칭 비용 왜곡·하류의 트랙 소멸 → 위험·잔여로 기록(선택 트랙은 지워지지 않으므로 하류가 참조하는 id 는 남는다).
- **구현 중 발견(Claude):** 같은 프레임에 다른 관측을 받은 중복 의심 트랙까지 지우면 그 관측이 버려짐(2B-3c 그래프 시험) → 예외 추가.

### 2판 (2026-10-18)

- **Codex 재검토**(P1 0 · P2 1): 탄생 분류(near_miss)는 흡수 시점의 판독 동등성을 보장하지 않음 — 이후 T11 판독을 받은 중복, 배치 구간이 갈라진 중복을 지우면 판독 정보가 사라져 이웃이 대상 관측을 받음 → 흡수 시점 포함 조건(`_reading_contains`), 두 경로 시험.

### 3판 (2026-10-18)

- **Codex 재검토**(P1 0 · P2 1): 가설이 없는 중복을 포함으로 인정한 방향이 거꾸로(가설 없음 = 어떤 알려진 판독도 받음) — 실제 보정표 반례에서 흡수 뒤 이웃이 대상 T11 판독을 받음 → 선택 트랙에 가설이 있으면 중복도 같은 가설을 가져야 함, 방향별 시험. 보정 집합 중복 프레임은 그대로 21.
