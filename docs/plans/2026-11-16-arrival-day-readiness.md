# 도착일(11-20) 준비 점검표 — 2026-11-16

절차서([도착일 절차](2026-11-12-arrival-day-procedure.md))와 M1–M3 등록([등록](2026-11-15-m1-m3-registration.md))을 기준으로, 항목마다 상태를 적는다. 상태는 **준비됨**(도구·문서·시험이 main 에 있음), **사용자 대기**(사용자가 할 일이 남음), **미착수**(아직 만들지 않음) 셋이다. 리허설 2 차 결과는 [기록](../validation/2026-11-16-arrival-day-rehearsal-2.md).

## 사용자 대기 — 사용자가 할 일

| 항목 | 사용자가 할 일 |
|---|---|
| STM32CubeProgrammer CLI | 노트북에 `STM32_Programmer_CLI`(2.21 이상)를 설치한다(지금 PATH 에 없음, 절차서 1·3 절). |
| udev 규칙 | 노트북(그리고 Jetson)에서 절차서 4 절 명령을 sudo 로 한 번 돌린다(지금 미설치). |
| A2M12 연결(G4) | A2M12 를 노트북에 연결해 `scan_check.py` 실측을 할 수 있게 한다. 이것이 7b(다리 스캔 원천)와 G6 실차 주행의 선행 조건이다. |
| Jetson LAN | Jetson 을 LAN 에 연결하고 접속 정보를 총괄에 알린다. 다리 정체 측정(nvpmodel 모드·jetson_clocks 고정·기록)과 실차 운용 경로 확인에 필요하다. |
| G9 참값 방법 | 등록 6 절의 (A) 바닥 표시 / (B) 천장 카메라 가운데 고른다. M1 끝 횡 오차와 M3 판정점 값이 이것에 달렸다. |
| D435i 실기 확인 | `python tools/imu_record.py --out data/imu_check/<날짜>.jsonl --seconds 120` 을 한 번 돌린다(약 3 분). |
| 모터 출력 보호 확인 기록 | 출력 열린 시운전 빌드(S3·S5)에 필요한 IPROPI 보호 확인 기록을 사용자가 작성·커밋한다(절차서 2 절, 사용자만 작성). |
| 현장 준비물 | 절차서 1 절 표의 물건(받침대·스트랩, 손에 쥐는 주 전원 차단 스위치, 승강 낙하 방지 블록, 멀티미터, 전류 제한 벤치 전원, 오실로스코프, 외부 리셋 버튼)을 갖춘다. |
| 콘솔 단말 | 운용자 단말을 정한다. 앞쪽 탭·화면 켬·유선 또는 AP 근거리로 두고, 측정 전에 텔레옵 송신 간격을 잰다(리허설 2 차 R2-3: 약 0.2 s 넘게 비면 그 시행은 void). |
