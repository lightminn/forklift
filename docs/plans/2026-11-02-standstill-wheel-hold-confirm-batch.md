## 2. S1 등록에서 바꾸는 것 (결과 전 개정)

1. **측정:** PR #252 를 머지한 main 으로 돈다. 정지 잠금 기록(`stand_wheel_locks`)과 탐침(`stand_probe`)이 그 틱의 truth 를 쓴다.
2. **캡처 빈틈:** 캡처 안에서는 물리 스텝 11 개가 제어·잠금·탐침 블록 없이 진행된다. 그래서 탐침에 약 0.1 s 빈틈이 생긴다.
   - S1 집계기는 그 빈틈에서 명령 0 연속을 끊었고, 상태 등가성 결함 6 틱이 났다.
   - 이번에는 앞뒤 줄이 모두 명령 0 이고(대상 단계 안) 그 사이에 줄이 하나도 없는 빈틈은 길이와 상관없이 명령 0 연속을 끊지 않는다.
     - 탐침은 제어 블록이 도는 틱마다 명령 0 줄을 쓰고, 명령 0 다음의 첫 비영 명령 줄도 쓴다(`RestartTail`). 그래서 줄이 없는 빈틈은 제어 블록이 돌지 않은 틱이고, 그동안 마지막 명령(0)과 잠금이 그대로다.
     - 길이 상한을 두지 않는 것은 캡처가 최대 200 회까지 다시 시도하기 때문이다(Codex: 31 스텝·0.258 s 뒤 정상 성공을 재현).
   - 명령 있는 줄과 대상 밖 단계는 지금처럼 끊는다. 이은 빈틈의 수와 가장 긴 빈틈을 보고한다.
   - 잇고도 켬 팔에 가상 정지 상태와 실제 잠금이 다른 틱이 남으면, 이번에는 판정 불가다(S1 에서는 보고만 했다).
3. **실행 목록·노출·최소 유효 짝:** 아래 §3·§4.
4. 그 밖의 정의(구간·가상 정지 상태·잠금 수명·재출발·서서 조향·방위)와 통과 조건 1–7, 유효성 규칙, 보고는 S1 등록 §4–5 그대로다.
