# DLS08 후보 자료

`dls08_provisional` 모델에 사용한 상품 원본은 Git에 복제하지 않는다. 원본 URL, 파일 크기와 SHA-256은 [`sources.json`](sources.json)에 기록한다. 자료가 필요하면 해당 URL에서 다시 내려받아 SHA-256이 기록과 일치하는지 확인한다. 다운로드한 원본은 `data/`에 두고 Git 추적 대상에서 제외한다.

이 자료는 사진과 카탈로그 외형이 대응하는 **DLS08 후보 제품**의 근거다. 프로젝트에 인도될 차체의 SKU 동일성, 실제 치수, 조향·구동·승강 구조 또는 성능은 실물 수령 전까지 미확인이다.
