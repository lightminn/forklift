# 6주차 발표 피드백

기록: 2026-10-07 · 발표 자료: <https://lightminn.github.io/forklift-presentations/week-06/>

발표 중 받은 피드백과 팀 메모를 주제별로 정리했다. 괄호 속 **팀 메모**는 피드백이 아니라 팀원의 의견이다.
확인이 더 필요한 항목은 맨 아래 [확인 필요](#확인-필요)에 따로 모았다.

## 1. 다음 일정 — 리보틱스 중간 미팅

- 리보틱스 중간 미팅(형식은 중간 발표)에서 할 내용을 대략 만들어서 **미팅 전에 교수님께 먼저 검사받는다.**
  - 초안 검사: 월요일(2026-10-12)
  - 리보틱스 미팅: 수요일(2026-10-14)
- (팀 메모: 지금 계획서대로 만들고 있고, 리보틱스 미팅 때 물어볼 것이 좀 있다.)

## 2. 발표 구성

- 보는 사람이 좋아할 만한 **비교 표**를 넣는다. 예: 실제 지게차 자격증 시험 기준과 우리 지게차 비교.
  - 3주차 피드백(국가공인 지게차 시험의 표준 운용 방법을 코드와 시뮬레이션에 적용)과 이어지는 항목이다.
- **결론 장표**가 필요하다. "무엇이 어떻게 달라지니까 무엇으로 가야 한다"는 형태로 결론과 방향을 같이 쓴다.

## 3. 경로 계획 — 후진과 선회

- **Hybrid A*가 왜 뒤로 가는지** 설명이 필요해 보인다. (발표 7쪽 새 장애물 재계획 장면에서 멈춘 뒤 조금 후진했다가 다시 출발한다.)
- **앞뒤로 돌 때의 특성**을 확인한다. (발표 8쪽 다음 작업에 조향각 15°에 맞춰 앞뒤로 여러 번 움직이며 방향을 맞추는 경로를 넣었다.)
- (팀 메모: 앞뒤로 돈다는 건 그냥 선회를 말하는 것 같다. A*도 우리에게는 거의 그레이 박스(내부 동작을 일부만 아는 상태)다.)

## 4. SLAM — LiDAR와 비전 비교

- 지금의 **LiDAR 기반 SLAM과 비전 기반 SLAM을 비교하는 장표**를 넣는다. LiDAR를 쓰는 근거를 보이기 위한 장표다.
  - 지금은 LiDAR 한 대와 slam_toolbox로 위치를 추정한다(발표 4–6쪽).
- (팀 메모: SLAM을 전문으로 하는 교수님이 따로 계시니, 차량 동역학처럼 우리가 잘하는 쪽 위주로 하자.)

## 5. 무선 통신

- (팀 메모: 지게차–PC든 지게차–지게차든 **무선 통신 자체를 아직 고려하지 않았다.** 설계에 넣어야 한다.)
