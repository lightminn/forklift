# 팔레트 인식 단계 2B-3d — yaw·받침 근소 실패를 중복 의심으로: 개발 평가 (2026-10-18)

계획: `docs/plans/2026-10-18-recognition-stage2b3d-near-miss-duplicates.md`(Codex 3회 수렴, agy 독립 검토). 사용자 결정(2026-10-18): yaw·받침 경계를 전체적으로 넓히지 않고, 활성 선택 트랙 근처의 근소 실패만 중복 의심으로. 범위는 2B-3 계열과 같은 **oracle 기하·추적 개발 증거**이고, 선택은 정답으로 대상을 처음 가리킨 트랙이다.

규칙: 새 트랙의 첫 관측이 활성 선택 트랙에 대해 위치·판독 관문은 통과하고, 포켓이 두 축 모두 0.2 m 안에서 움직였으며, yaw 차이 ≤ min(1.5 × 관문, 30°)·받침 차이 ≤ 2.5 × 관문이면서 < 45 mm 로만 떨어졌으면 중복 의심. 보정표·W 는 2B-3c 그대로(같은 보정 집합으로 다시 돌려 행·W 동일 확인).

## 판정: 고정 기준 불합격 — V2(곡선)는 중복 트랙 기준만 남음

## 원인 (보정 집합에서 진단 — 평가 집합은 판정 한 번만 읽음)

보정 집합(2B-3c 와 같은 102 시퀀스, V1)에서 같은 진단(`diag_other2`)을 2B-3c 와 2B-3d 추적기로 돌렸다.

| | 2B-3c | 2B-3d |
|---|---|---|
| 선택 트랙에도 맞았지만 다른 트랙이 받음(경쟁) | 16 | **2** |
| 그 상대 트랙의 탄생 원인 | yaw 8, 받침 8 | yaw 2 |
| 선택 트랙이 지워진 뒤의 대상 관측 | 85 | 68 |
| T11 면 전환 / 자세 관문 / 배치 관문 | 8 / 7 / 6 | 8 / 7 / 6 |
| 대상 중복 트랙 프레임 | 22 | **28** |

1. **근소 실패 규칙은 의도대로 경쟁을 막는다**(16 → 2).
2. **대상 중복 트랙 프레임은 오히려 늘었다**(22 → 28). 중복 의심 표시는 새 트랙 생성을 막지 않고, 선택 트랙이 더 오래 살아남으면서 중복 의심 트랙과 함께 대상을 가리키는 프레임이 늘었다 — 계획 위험 절에 적은 잔여 실패다. 고정 기준의 "중복 0" 은 중복 의심 트랙을 지우거나 합치지 않는 한 넘기 어렵다.
3. V1 의 S2 사례별 미달과 유지율 94.4 % 의 원인은 이 평가 집합에서 따로 진단하지 않았다(평가 집합은 판정에만 쓴다).

## 다음

- **중복 의심 트랙의 처리:** 선택 트랙이 관측을 가져간 프레임에, 같은 관측에 맞는 자기 중복 의심 트랙을 지우는(선택 트랙으로 흡수하는) 규칙이 중복 기준의 남은 경로를 막는다. 사용자가 앞서 고른 B 안의 연장(선택 트랙의 중복 의심에만 적용)이지만 트랙을 지우는 결정이라 설계 판단이다.
- 3.0–3.5 m 개선 부족(2B-3 부터 같음), T11 면 전환(설계상 실패).
