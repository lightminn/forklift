## 남은 실패의 원인 (보정 집합에서 진단 — 평가 집합은 판정 한 번만 읽음)

보정 집합(102 시퀀스, V1, 선택 대리가 `select` 를 부름)에서 대상 관측이 선택 트랙이 아닌 다른 트랙으로 간 경우를, 선택 트랙의 수명을 `update()` 와 같은 조건(keep_s 1.0 s)으로 확인하고 분류했다(`diag_other2`).

| 경우 | 건수 |
|---|---|
| 선택 트랙이 이미 지워진 뒤(수명 만료 — 관문 문제가 아님) | 85 관측 |
| 선택 트랙에도 맞았지만 **진짜 이웃으로 분류된** 다른 트랙이 받음 | 16 |
| 선택 트랙의 **자세 관문**에서 떨어짐 → 다른(이웃 분류) 트랙 | 7 |
| T11 면 전환(x ↔ y) — 선택 트랙의 판독 관문에서 떨어짐, 중복 의심 트랙이 받음 | 8 |
| 비규격 배치 관문에서 떨어짐, 중복 의심 트랙이 받음 | 6 |

1. **자세 관문의 근소한 실패가 남은 경쟁의 근원이다.** "진짜 이웃으로 분류된" 상대 트랙 16 건은 모두, 대상 관측이 선택 트랙의 자세 관문에서 **yaw(8)** 또는 **받침 높이(8)** 로 떨어져 태어난 트랙이다. 판독 관문이 아니라 자세 관문에서 갈라졌기 때문에 중복 의심으로 표시되지 않았고, 이후 같은 팔레트 관측을 두고 선택 트랙과 겨룬다. yaw·받침 경계(단일 프레임 p95 두 개의 합 + 주행 기록 상한)를 p99 로 넓히거나, 중복 의심 정의를 "yaw·받침에서만 근소하게 떨어진 경우"까지 넓히는 것이 다음 후보다 — 둘 다 이웃 오연결 위험과 맞바꾼다. 가로·삽입축에서 떨어져 태어난 경쟁 트랙은 없었다.
2. **T11 면 전환**(8 건)은 설계 §8 대로 추적 실패다 — 정사각 T11 을 비스듬히 볼 때 판독 면이 바뀐다.
3. 비규격 배치 관문(6 건)은 p99 로 넓힌 뒤에도 남는다.
4. 선택 트랙이 지워지는 것 자체는 위 경쟁·전환·미확정으로 관측을 잃은 결과다(1.0 s 공백).
5. 3.0–3.5 m 개선 부족은 그 구간 창(1.2 s) 안의 앞 관측이 더 멀고 나빠서다(2B-3 부터 같음).

(1판 기록은 선택 트랙 수명을 확인하지 않아 삭제 뒤 관측 8 건을 경쟁·면 전환으로 셌고, 상대 트랙의 생성 축을 가로·삽입축·yaw 로만 적었다 — Codex 지적으로 고침.)
