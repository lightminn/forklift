- **τ = 0.3:** `choose_tau` 규칙(설계 §3.4 상한을 모집단별로 모두 만족하는 가장 낮은 τ, 없으면 미달이 가장 작은 τ)이다.
  - 상한을 모두 만족하는 τ 는 없다. 절대 놓침·확인 요청 상한은 **정답 마스크 맞춤 자체도 넘는다** — 팀 잡음 `oracle-fit` 이 EPAL 6 73/252, T11 110/252, S7 79/135 를 놓친다. 학습 경로의 손실은 위의 "새로 틀린" 비율로 본다.

- **음성 오검출은 grounded 에서만 난다.** 학습 데이터의 N 장면에도 grounded 가 방해물(배경)로 들어 있었지만, 모델은 grounded 를 높은 점수로 팔레트라 부르고, 단계 2 맞춤도 기하로 받아들인다. ADR 0004 D6 이 이 집합을 둔 이유가 바로 이 결함이다(CPU 스윕에서 실제 팔레트와 같은 비율로 유효). 앞 면에서 밑판 띠 하나 차이라 RGB 로도 깊이로도 어렵다. 다음 단계의 과제로 남긴다.

## 작업 6 — Isaac 미션

M-c 미션 구성 배치에 `--recognition far --recognition-proposals learned` 를 붙였다. 인자는 YOLO11s ONNX, τ 0.3, conf 0.05, 픽셀 지연 24 이고, 워커는 학습 venv·CPU 4 스레드다. snapshot 은 `9dbd8c7` 이다.
- 원거리 관측의 제안은 학습 제안기가 RGB 로 낸다. 의미 분할은 평가 기록(지연 추정의 정답 대응)에만 쓴다.
- 대조 `off` 는 같은 미션의 기존 실행(`k_off_s{0,1,2}`, snapshot `6b9cbcb`)이다. off 경로는 이 브랜치에서 바뀌지 않았다. 정답 마스크 실행은 `m_far_s{0,1,2}`(`12c10db`)다.

- **J1**(사이클 성공, 출처가 새 인식, `selected`, 오차가 평가 p95 안): 3/3.
- **J2**(융합 연결): seed 0·1 은 지연 일치, 융합 관측 2·3 개로 통과다. seed 2 는 정답 마스크 실행과 똑같이 다리 0 이 분실로 끝났고, 재관측 다리 1 은 지연 판독이 6 개 미만이라 판단이 없다. 융합 관측 3 개다.

- 근거리 보정량(원거리 추정 → 근거리 추정 xy 차)은 기존 검출기가 근거리를 잡은 값이다. seed 1 의 63 mm 는 정답 마스크 실행(33 mm)과 다르지만, 같은 원거리 추정의 참값 대비 위치 오차는 둘 다 28 mm 로 같다. 차이는 근거리 쪽이다. 같은 설정의 이전 실행(`72a30db`, 스레드 미고정)에서는 73 mm 였다 — 근거리·주행이 실행마다 조금씩 다르다.
- **재계산:** 세 실행 모두 `tools/recompute_far_recognition.py <run> --onnx <best.onnx>` 결과가 "same" 이고 종료 코드 0 이다.
  - 저장 제안 재생: 판정·출처·선택 트랙·사용 후보가 같다.
  - 모델 재실행: 수치 검사(개수·점수·IoU)와 판정 전체가 같다.

## 추가 — GPU 실행 (2026-10-19, `feat/recognition-stage3b`)

- **원인:** 학습 venv 의 onnxruntime-gpu 가 pip 로 깔린 CUDA 13·cuDNN 라이브러리를 찾지 못해 조용히 CPU 로 돌았다. torch 를 먼저 import 하는 스크립트에서만 CUDA 가 켜졌다. Slurm 잡에는 `CUDA_VISIBLE_DEVICES=0` 으로 RTX 5070 Ti 한 장만 보이고, 노드의 AMD 내장 GPU(Raphael)는 CUDA 장치가 아니다.
- **고친 것:**
  - CUDA 를 요청하면 `preload_dlls()` 로 라이브러리를 먼저 올린다.
  - 장치를 `device_id` 로 명시한다(`--recognition-device-id`).
  - onnxruntime 의 실행 중 CPU 재시도를 끈다(`disable_fallback`).
  - 세션이 CUDA 가 아니면 생성 때와 예열 뒤 모두 오류를 낸다. 실행 기록에는 실제 활성 공급자를 남긴다.
  - 워커는 첫 요청 전에 예열하고, 프로토콜 출력을 별도 서술자로 분리했다(라이브러리 진단 출력이 응답 스트림을 깨지 않게).
  - 기본 공급자는 CPU 만이다.
