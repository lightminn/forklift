  | F1 | 86.8 · 23.2 / 47.9 · 77.5 | 153.8 · 49.2 / 6.7 · 74.1 |
  | O+F2 | 74.4 · 73.9 / 53.2 · 53.5 | 120.5 · 120.8 / 30.2 · 31.9 |
  | F1+F2 | 55.2 · 54.8 / 62.6 · 62.9 | 101.3 · 101.7 / 39.6 · 41.2 |

  - 관측: 강체 팔은 하중이 대각으로 치우치고, O 적재의 뒤 왼쪽 바퀴는 거의 하중을 받지 않는다(0.003 N). 순응 팔은 좌우가 거의 같다.

| 대비 | M1(8 상태) | M2(20 구간) |
|---|---|---|
| F2\|O(= 후보 F2 단독) | 통과(구분 8, 부호 1.00, 크기 1.00) | **dt 의존**(구분 20, 부호 0.95, 크기 12/20 = 0.60) |

## 결론(총괄 결정, 11-05)

- **종결 상태:** 이번 등록에서 후보를 고르지 않았다. (나) 운영 회귀는 내지 않았다. **F2 는 승격 보류**다. 운영 기본값은 바뀌지 않는다. v2 계획은 지금 쓰지 않는다.
- **보류의 중심 근거:**
  1. M2 는 네 팔·두 dt 모두 유효한 비교였는데, 그 비교에서도 모든 후보가 4.4 dt 조건을 통과하지 못했다(dt 의존).
  2. 운영 이득을 확인하지 못했다((나) 미실시).
  - 초기 상태 통제 미충족(M1 강체 팔의 이력·순서 의존성, M3·M4 F2 팔의 재정착)은 추가 사유다.
  - 재료 값(k·c)이 실차 측정이 아닌 일반 고무 대푯값이라는 점은 보류 근거로 쓰지 않는다.
- **읽는 법:**
  - 역순 차는 **이력·순서 의존성**이다. 같은 순서의 두 새 프로세스는 판정 도구의 결정성 검사를 통과했으므로, 역순 차이를 비결정성의 증거로 해석하지 않는다.
  - F2 팔의 재정착 미수렴은 **운영에서의 크리프 위험 가능성**으로만 적는다. 유효 시행끼리의 M3 셈은 F2 효과가 악화 0·개선 40 이다.
  - F1|F2 가 작다는 것은 **F2 아래에서 F1 의 추가 효과가 작다**는 뜻이다. 교호작용 I(M2 중앙 4.6·최대 14.0 mrad)와는 다른 양이다.
  - F2 의 M2 효과(중앙 16.9 mrad)는 Δ|e_L − e_R| 다. 운영의 e_L(29–30 mrad)과 같은 차수지만 같은 양이 아니다. **유망한 기전 신호**로만 남긴다.
- **재검토 계기(재개 조건이 아님):**
