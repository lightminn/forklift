# F2 뒤 남은 '좌우 조향 비대칭' 재확인 — 거울 비교 (2026-11-18)

- 배정(총괄, 사용자 지시 2026-11-18): 순응 타이어 F2 뒤에도 남은 좌우 조향 비대칭 8–19 mrad([F2 재등록](2026-11-18-f2-i-reregistration.md) 3.2 의 A)의 모형 쪽 원인을 [모형 대칭 확인](2026-11-17-model-symmetry-check.md)(#573)에 이어 한 번 더 본다. 모형 결함이면 고치고, 아니면 실측 대기로 기록한다. 새 Isaac 실행은 없다. 원자료는 커밋된 `assets/f2i-reregistration/mechanism.json` 이다.

## 1. A 가 재는 것

- 재등록 도구(`2026-11-18-f2-i-reregistration/mechanism.py`)의 A 는 한 층(전진·후진 × 왼·오른 회전 × 저·고속, 곡률 포화 구간) 안에서 `|mabs[0] − mabs[1]|` 이다. `mabs` 의 두 값은 **왼쪽·오른쪽 앞바퀴**의 평균 |명령 − 실제| 조향각이다(러너 `steers` 순서 `left_steer`, `right_steer`).
- 그러니까 A 는 **같은 회전 안의 안쪽 바퀴 대 바깥쪽 바퀴** 차이다. 애커먼 조향에서는 안쪽 바퀴가 더 크게 꺾인다. 그래서 좌우가 완전히 대칭인 차체에서도 A 는 0 이 아니다. A 만으로는 좌우 비대칭인지 알 수 없다.

## 2. 거울 비교

같은 역할의 바퀴를 두 회전 방향 사이에서 비교한다. 왼쪽 회전의 안쪽(왼쪽 바퀴)과 오른쪽 회전의 안쪽(오른쪽 바퀴), 바깥쪽끼리도 같다. 대칭인 차체라면 0 근처다. 두 회전 층이 모두 유효한 방향·속도만 센다.

| | O(강체, 운영 이전) | F2(순응 타이어, 지금 기본) |
|---|---|---|
| 층 짝 수 | 25 | 20 |
| 안쪽 바퀴: 왼쪽 회전 − 오른쪽 회전, 중앙(범위) | **+32.9 mrad**(−2.7–35.0) | **−0.06 mrad**(−6.5–10.2) |
| 바깥쪽 바퀴: 같은 차, 중앙(범위) | **−27.6 mrad**(−32.0–−9.5) | **−0.3 mrad**(−3.8–2.7) |
| 같은 층 안 안쪽−바깥쪽(= A), 왼쪽·오른쪽 회전 중앙 | 33.0 · 29.4 mrad | 16.6 · 17.1 mrad |
| 달성/명령 곡률 비, 왼쪽·오른쪽 회전 중앙 | 0.877 · 0.838 | 0.923 · 0.923 |
| 노출 시간 합, 왼쪽·오른쪽 | 204.0 · 231.8 s | 121.4 · 107.4 s |

- **O 는 진짜 좌우 비대칭이었다.** 왼쪽 회전에서 안쪽(왼쪽) 바퀴 오차가 오른쪽 회전의 안쪽 바퀴보다 약 33 mrad 크다. 바깥쪽은 반대 방향으로 약 28 mrad 다. #573 이 본 '왼쪽 앞바퀴에 몰린 오차'와 강체 네 점 접촉의 대각 하중(FL·FR·RL·RR 115·33·31·76 N)과 맞는다.
- **F2 에서는 거울 차가 사라졌다.** 안쪽·바깥쪽 모두 중앙값이 0.3 mrad 안이다. 왼쪽·오른쪽 회전의 곡률 비도 0.923 으로 같다. F2 의 정지 하중도 좌우 같다(74.4·73.9·53.2·53.5 N, 재등록 4 절).
- **F2 에 남은 8–19 mrad 는 안쪽·바깥쪽 바퀴 차이다.** 왼쪽 회전과 오른쪽 회전에서 크기가 같다(16.6 · 17.1). 이 층들은 곡률이 포화된 구간이라 안쪽 바퀴가 조향 한계 가까이에서 더 크게 꺾인다. 그래서 안쪽 바퀴의 추종 오차가 크다.
- 경로의 좌우 편중: F2 노출 시간이 왼쪽 121.4 s·오른쪽 107.4 s 로 크게 치우치지 않았다. 거울 차는 층마다 따로 재므로 편중이 결과를 만들지 않는다.

## 3. 판정

- **모형 결함으로 볼 근거 없음.** F2 아래에서 좌우 거울 차는 0 근처이고, 남은 값은 대칭 차체에서도 생기는 안쪽·바깥쪽 차이다. 고칠 것이 없다.
- '좌우 비대칭 8–19 mrad' 라는 이름은 맞지 않는다. 앞으로 이 값은 '안쪽·바깥쪽 바퀴 추종 차'로 부른다. 그 크기(안쪽 바퀴가 한계 근처에서 얼마나 늦는지)가 실차와 맞는지는 **11-20 실차 M2(조향 대비 실제 곡률) 실측을 기다린다.**

## 4. 한계

- 원자료는 재등록의 13 사례·결정 모드다. 곡률 포화 구간만 센다(도구 정의). 저속 층이 대부분이고 고속 층은 노출이 거의 없다(재등록 6 절).
- 범위의 끝값(안쪽 +10.2 mrad: random_1 s5 후진 저속, 노출 1.6·2.5 s)은 짧은 층이다. 층 하나의 값으로 좌우를 말하지 않는다.
- 조향 관절 armature·마찰, 바닥 재질 결합은 #573 범위 밖 그대로다. 거울 차가 0 근처라 이번 결론에는 필요하지 않았다.
