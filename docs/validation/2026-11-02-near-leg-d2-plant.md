# 근접 다리 계획 D2′ 2 부 — 적용 명령에서 plant (등록, 2026-11-02, 검증 예측 전)

계획: `docs/plans/2026-11-02-near-leg-end-stall.md` 1.6 D2′ 의 2 부. 이 문서는 **검증용 실행의 예측을 보기 전에** 목록·모델 구조·입력 정렬·지표·기준을 고정한다. 결과는 같은 문서의 아래 절에 덧붙인다.

## 자료

- S1 배치 `st_b3e3ea7f`(코드 b3e3ea7f, 질량 10 kg) 실행 66 건의 `run/result.json`(0.1 s 표본)과 `run/slam_log.npz`(120 Hz 관절·truth).
- 입력은 표본의 적용 명령이다. `speed_command_mps` 와 `steering_command_rad` 는 `drive = ackermann(...)` 뒤의 값이다. 0.1 s 값을 관절 시각(120 Hz)에 선형 보간한다. 보간은 이번 식별의 한계로 둔다(틱 단위 적용 명령은 경계 기록에만 있다).
- 출력은 `slam_log` 의 `steering_rad`(관절각)와 `base_pose_world`(x y z qw qx qy qz) 에서 낸 truth 후축 자세(차체 원점 − 0.34 m · 전방)다. 진단 기록에서 `slam_control.npy` 의 truth 후축과 0.0 mm 로 일치함을 확인했다.

## 목록

- 제외(진단·회귀 전용): st_off_random_1_s2, st_on_random_1_s2, st_on_random_1_s5, st_on_random_1_s9.
- 식별: 두 팔 × {random_1 s0·s1·s3, aisle_rack s0·s1, line_2 s0·s1, trailer s0}(16 실행).
- 검증: 나머지 전부(46 실행). 실행 단위로 나누고 틱을 섞지 않는다.

## 모델과 지표

- (a) 조향: 바퀴마다 적용 조향 명령 → 1 차 지연 τ(0.05–0.30 s, 0.01 간격) + 지연 시간(0, 0.025, 0.05 s). 식별 실행의 두 바퀴 합동 RMSE 최소로 고른다.
- (b) 운동: 적용 속도 → 1 차 지연 τᵥ(0, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5 s). 곡률은 모의한 두 바퀴 각에서 k = (tan δL + tan δR)/(2L)로 내고, L 은 식별 실행의 (적용 곡률, 적용 각)에서 중앙값으로 맞춘다. 후축 운동학을 쓴다.
  - 창: 3 s 창을 1 s 마다 둔다(적용 속도 |v| > 0.05 m/s 가 있는 창만). truth 후축 자세와 truth 속도에서 출발한다.
  - 창 끝에서 truth 대비 |방위 오차|와 truth 방위 기준 |옆 오차|를 잰다. τᵥ 는 식별 창의 방위 p95 최소로 고른다.
- 도구: `tools/near_leg_d2_plant.py`(이 커밋, md5 는 결과 절에 적는다). ws1 Slurm CPU 잡으로 돌린다. 총괄 기준의 "ws1 제출" 1 회로 센다.

## 기준 (검증 실행)

- (a) 합동 RMSE ≤ 0.02 rad, 그리고 실행별 p99 ≤ 0.06 rad 가 검증 실행의 95 % 이상.
- (b) 창 끝 |방위 오차| p95 ≤ 0.02 rad, |옆 오차| p95 ≤ 0.02 m.
- 처분:
  - 둘 다 만족하면 D2′ 3 부(제어 포함 굴림)로 간다.
  - (a) 만 만족하면 조향 응답은 검증, 운동 쪽은 미검증이다. 바퀴 쪽 힘·감쇠·미끄럼·차체 곡률 응답을 후보로 둔 2 차 식별(제출 2 회째)을 한 번 한다.
  - 2 회째에도 기준에 못 미치면 총괄 기준에 따라 C2 를 먼저 진행한다.
- 이 기준은 "기록을 재현하는가"의 판정이다. C1 에서 K3 문턱 근처를 어떻게 다룰지는 3 부에서 이 모델의 오차 분포로 따로 정한다.
