## 기록 손실 (V3a s8 on)

- 미션은 `home_settle` 까지 갔다(`frames.jsonl`). 하지만 최종 하역 판정(`delivery_verdict`)은 미션이 끝난 뒤(`complete` 확인 다음)에 실행되므로, 이것만으로 하역 판정을 통과했다고 할 수 없다. 그래서 하역 결과는 결측이다.
- `result.json` 쓰기는 `ValueError: Out of range float values are not JSON compliant: nan` 으로 실패했고, 그 뒤 Kit 종료 중에 세그폴트(rc 139)가 났다.
- 원인: #302 가 on 일 때 남기는 라운드별 기록이 그 라운드의 dry run 을 복사한다. `bicycle_rollout` 은 시간 초과면 위치·요 오차가 NaN 이다. 최상위 값은 다음 라운드가 덮어쓰지만 라운드 복사본에는 NaN 이 남았다. 고침은 PR(fix/round-record-nan)로 따로 냈다.
- 등록 규칙대로 이 실행은 실패로 셌다(off 만 성공 1).
- 물리 청결도는 프레임에서 다시 쟀다([`rebuild_result.py`](2026-11-05-line2-robustness-v3/rebuild_result.py)):
  - 방법: 같은 장면·seed 의 off 실행 기록에서 장면·형상을 쓰고, 이 실행의 `frames.jsonl`(10 Hz)·`slam_control.npy`·`slam_log.npz`(조향)로 대체 기록을 만들어 `low_clearance_report.py` 에 넣었다.
  - 검증: 같은 방법으로 off s8 을 다시 만들면 실제 기록과 똑같이 나온다(차 0.379 m, 팔레트 0.456 m, 정지 호 위반 0).

- 따라서 D1 해당·0.6 m 정지 설치·재시도 수(위 표)는 기록이 남은 실행에서 관측한 수다. s8 on 은 세지 못했다.
