## 적용(합격 분기, 총괄 결정 2026-11-11)

- `deploy/console/isaac_live.sbatch`: 단독 라이브(콘솔·시연)의 기본 CPU 예약을 6 으로 올렸다.
  - 잡의 CPU 를 단일 슬롯 묶음과 같은 함수로 나눈다(`split_bridge_cpus`/`auto_bridge_cpus`). 브리지에 온전한 코어 하나를 주고, 세션(`run_transport`)은 나머지 코어 둘에 `taskset` 으로 고정한다. 등록 B 와 같은 배정이다.
  - CPU 4 로 내면 코어 하나씩이고, 그보다 적으면 나누지 않는다. 묶음 안에서는 `BRIDGE_CPU` 와 묶음 실행기의 고정을 그대로 쓴다.
- `tools/isaac_bundle.py sizes --session-cores 2`: 세션당 코어 둘의 잡 크기를 낸다. 기본은 1 그대로다(큰 배치는 등록마다 정함).
- 실시간 측정 래퍼(r1c 등)는 바꾸지 않았다. 다음 측정 등록이 정한다.
- 적용의 한계:
  - 판정은 line_m far K f 1.0 confirm, seed 0, live 모드, 단일 슬롯 조건의 값이다.
  - ws1 동시 수용량이 줄어든다. 콘솔 한 세션이 CPU 4 → 6 을 쓴다. 노드 CPU 20 에서 콘솔 셋이면 18 이다.
