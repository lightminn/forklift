- 결과: 완주 세션 3 / 10, 완료 미션 18 / 25(72.0 %, 수락·실행 기준; 결과 파일이 남은 미션만 세면 18 / 23), 금지 접촉 0.
- PR ④ q2_0136fc5 는 완주 세션 5 / 10, 완료 미션 17 / 21(81 %), 금지 접촉 0 이었다. 그 21 은 결과가 남은 미션 수다. 그 묶음에는 진행 중 미션을 잘라 결과가 빠지게 한 실행기 중단이 없어 두 기준이 같다(미션이 끝난 뒤 SIGTERM 된 실행 3 건은 미션 파일이 온전하다).
- 바뀐 것
  - P-4 원거리 인식 실패(`observe:stall_exhausted`)가 이 묶음에서는 두 팔 모두 0 이다. PR ④ 에서는 2 실행, 1 차 묶음에서도 2 실행이었다.
  - 대신 세션을 끝낸 주된 실패가 새로 드러났다: SLAM 연결 시간 초과 4 실행(두 팔 합), 하역 복구 실패 2, 장면 재계획 시간 초과 2, 복귀 추종 실패 2.
  - 두 팔을 합치면(차량 코드는 같다) 완주 세션 8 / 20, 완료 미션 41 / 53(77.4 %, 수락·실행 기준)이다.
- 그래서 8 주차 목표(연속 이송 완주)는 아직 충족되지 않았다. 남은 주된 원인은 세션 끝 무렵의 SLAM 연결 시간 초과(콘솔 세션 조사 중)와 하역 복구·재계획 시간 초과다.
