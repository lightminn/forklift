# Isaac Sim: 팔레트까지 주행·삽입·운반·하역

사용자가 앞선 창고 배치 검사에 이어 실제 주행과 기존 팔레트 모델의 운반을
요청했다. NVIDIA Full Warehouse 안에서 **바퀴 구동 → 포크 삽입 → 접촉으로
승강 → 후진 운반 → 하역 → 포크 인출**을 실행했다. 시뮬레이션 시간 약
38.46초에 팔레트를 1.804 m 옮겼다.

  운반 목적지의 지게차 기준 x = −0.2 m. 위치·자세 피드백은 시뮬레이터 정답이다.

  접속·설치 경로는 Git 제외 `ENV.local.md`에 기록했다.

이 코드는 `artifacts/`에 보존한 일회성 물리 운반 실험이다. 카메라로 팔레트를
검출하거나 포켓을 추적하는 폐루프는 연결하지 않았다. 장애물 회피 경로계획,
최단시간 최적화, B–D 시나리오, 실물 제어기 검증으로 해석하지 않는다.
색상 문제는 사용자 요청대로 이번 작업에서 다루지 않았다.

## 물리 설정과 명령

원본 팔레트 URDF에는 관성이 없어 실행용 복사본에 **합성 질량 10 kg**을 넣었다.
22개 상자의 체적으로 질량을 나눠 무게중심과 관성텐서를 계산했다. 실측값이나
EPAL 공식 질량으로 주장하는 값이 아니다. 원본 URDF는 보존했다.

지게차 충돌 형상 55개와 팔레트 충돌 형상 22개를 사용했다. URDF importer가
충돌 그룹을 인스턴스로 가져오므로, 실행용 USD에서 해당 그룹의 인스턴싱만
풀어 다음 설정을 적용했다.

| 항목 | 실험 설정 |
|---|---|
| 로봇·팔레트 정지/동적 마찰계수 | 0.8 / 0.7, 합성 가정 |
| 반발계수 | 0 |
| contact/rest offset | 2 mm / 0 mm |
| articulation solver 위치/속도 반복 | 32 / 8 |
| 물리 간격 | 1/120초 |
| 바퀴 | 4개 속도 드라이브, 각 3 N·m 제한 |
| 조향 | 앞바퀴, 각 4 N·m 제한 |
| 승강 | 위치 드라이브, 180 N 제한, 목표 0.20 m |
| 접근/삽입/운반/인출 최대 속도 명령 | 0.30 / 0.07 / 0.22 / 0.12 m/s |
| 속도 명령 변화율 제한 | 0.22 m/s² |

포크 삽입 목표는 기존 모델의 406 mm 한계보다 짧은 **360 mm**다.
위치·방향 오차를 읽어 바퀴 속도와 조향 명령을 갱신하고, 목표 위치에 도착하면
승강·운반·하역으로 전환했다. 정지 조건과 팔레트 높이·상대 위치 조건을 함께
검사했다.

초기 배치 이후에는 지게차나 팔레트의 pose를 직접 지정하지 않았다. 팔레트는
자유 강체이며 포크와의 고정 조인트나 부착 장치를 만들지 않았다. 팔레트와
바닥·포크의 접촉이 승강과 운반을 결정한다. 카메라 pose 지정은 관찰 구도용이다.
