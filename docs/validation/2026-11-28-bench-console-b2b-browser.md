## 1. 실제 벤치 백엔드(B2a + 모형)에서 화면으로 실행

`python tools/bench_console.py --model <감싼 mcu_model> --port 8791 --runs-root <폴더>` 로 띄웠다. 감싼 모형은 HIL 시험처럼 `--kth-start-raw 1000,1000` 을 붙인다(모형의 KTH 가 원시 0 에서 시작하면 hold 의 ARM 이 거부된다 — 모형 조건이지 코드 문제가 아님).

화면 확인 중에 고친 것(같은 PR):
- 시작 버튼 문구가 새 문구 키에 덮이던 것, 결과의 '허용 오차 안' 비율이 빠지던 것, 해당 없는 결과 줄이 'null' 로 찍히던 것.
- **센서 방향 선택지 순서**: 객체가 정수 같은 키("1")를 빈 키보다 앞에 두어 축을 바꿔도 방향이 +1 로 남던 것을 고정 순서로 바꿨다.
- Codex 화면 검토 1 회차 반영:
  - 위치 유지의 출력 상한을 듀티와 다른 칸으로 해 모드가 바뀌어도 고정 출력이 되지 않음;
  - 목표 종류가 바뀌면 값 칸을 비우고, 축·원천이 바뀌면 목표를 '선택(필수)' 로;
  - 브라우저가 못 읽은 숫자(`1e` 등)는 빈칸이 아니라 입력 오류;
  - 바퀴 수가 생기면 이동량 상자를 끔;
  - 5.1 구성 표시는 속도 검사에만, 어긋나는 물리 구성과는 함께 안 보냄;
  - 한 카운트보다 작은 바퀴 수·wire 0 출력은 화면이 먼저 막음;
  - 멈춘 자리는 백엔드의 누계로, 보류된 이동량은 '보류', 결과를 못 받은 거리 실행은 '판정 불가';
  - 직전 결과(회수)·실행 당시 우회·메모·사본 실패·안내를 결과에 보임;
  - 그래프는 실행 축의 오차만;
  - 문구('받아들임', 입력 확인 문구, '아직 지원하지 않음(다음 단계)').

## 3. ACK 유실 뒤 재연결(4 절 (a''))

스크립트 백엔드 `bench-mute`(보드 FAULT, `--mute-stop`). 연결 A(epoch 4242, 8 s 뒤 닫음)에서 화면의 시작·고장 해제(원인 'replay')·패널 STOP 을 눌렀다(A 에서 패널 STOP 의 source 는 `bench`). 바로 다음 소켓 B 는 welcome 이 3 s 늦다.

- 같은 epoch(4242, `r2_same_a/b`): B 의 welcome 전에 받은 것은 A 의 그 id 의 `stop` 뿐, B 전체에서 `bench_run`·`clear_faults` 0 건, lease 는 B 에서 다시 요청.
- 바뀐 epoch(5151, `r2_epoch_a/b`): A 에 STOP id 가 둘(패널 STOP 이 두 번 들어감)이고, B 의 welcome 전에는 그 두 id 의 `stop` 만 받음. `bench_run`·`clear_faults` 0 건, lease 회수 요청 없음.

C 의 기록과 같다.
