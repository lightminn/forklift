- 적용 조건이 있다. 층 작업자가 스스로 CPU 를 고정하지 않을 때만 적용한다. 곧 mode 가 thread 가 아니고, cpus 와 affinity 가 None 일 때다. thread 모드 기록은 두 필드를 그대로 비교한다.
- 개수는 남겼다. 그래서 CPU 집합의 크기가 다르면 여전히 다르게 판정된다.
- Codex 가 검토했고 반박은 없었다.
- 이 예외로 내는 결론은 좁다. 이 두 쌍의 차이는 환경 기록이었다는 것뿐이다. CPU 친화성이 계산에 영향을 주지 않는다는 일반 보장은 아니다. slam_toolbox 안의 OpenBLAS·Ceres 같은 라이브러리 내부 스레드의 영향은 배제하지 않았다. 두 집합은 모두 CPU 6 개였다.
- 적용 방법은 `lat_budget_analyze.py --determinism-without-affinity` 다.

## 해석과 한계

- 아래 해석은 Codex 와 합의한 것이다.
- 예산 B = 0.10 은 정지 모델 지연을 0.15 s 에서 0.25 s 로, FREE 사용 나이를 0.2 s 에서 0.3 s 로 올린다. 이 값들은 observe 단계의 허가 속도 상한에 들어간다.
- random_1 에서 비교한 예산 실행은 모두 같은 seed 의 B0 보다 18–35 s 먼저 approach 에 들어갔다.
- 이 궤적 변화는 예산이 낸 효과의 일부다. 교란 요인으로 빼지 않는다. 원인은 정해지지 않았고, 결함은 그대로 남는다.
