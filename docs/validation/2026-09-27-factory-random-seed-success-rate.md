# 공장 모드 무작위 seed 40 개 — 운반·복귀 완주율

## 범위

사용자 요청(2026-09-27): 「공장 seed 를 무작위로 추가해 테스트를 더 진행하고 성공률을 확인.」
지금까지 공장 모드 결과는 개발 중 고른 seed(0–5, 16)뿐이었다. 개발에 쓰지 않은 seed 를 미리 정한
규칙으로 뽑아, 교체·제외 없이 모두 센다.

입력은 전부 `synthetic` 이다. **정답 팔레트 좌표(인식 미사용)**, 로봇 자세·충돌 지도·목적지는 시뮬레이터
정답, 기본 속도(`config/isaac_transport.yaml`), 영상 끔. 이 수치는 이 합성 배치 생성기와 이 조건에서의
완주율이며 실물 성능이나 인식 포함 임무의 성공률이 아니다.

## seed 선택

`random.Random(20260927).sample(range(20, 10000), 40)` 을 정렬한 값이다(0–19 는 개발에 써서 뺐다).

```

4182 4263 4646 4812 5115 5151 5205 5774 5940 6646 6651 6965 7027 7648 7991 8131 8285 8551 8841 9945
```

## 실행

ws1, RTX 5070 Ti, Slurm `compute`, Isaac Sim 5.1, `snapshots/default_regression_v2`
(`run_transport.py` SHA-256 앞 16 `835c9ce1ca8cdde7`, 커밋 `e9905d6` 과 같은 코드).
`run_transport.py --layout factory --return-home --max-sim-seconds 600`, 작업 336·337(각 20 seed)과
재실행 398, 32 GB. 원본: ws1 `artifacts/20260927_factory_random40/`.

같은 seed 의 CPU 계획(`tools/factory_planning_sweep.py`, 로컬
`artifacts/20260927_factory_random40_planning/`)을 먼저 돌렸다.

**성공 판정.** 접근 → 삽입 → 들기 → 인출 → 운반 → 하역 → 이탈 → 출발 자세 복귀까지 끝나고
`success: true` 인 경우. 계획 실패도 실패로 센다.

**Isaac 시작 크래시.** seed 3933·8841 은 첫 시도에서 Isaac 이 앱 시작 직후, 장면 구성·계획 전에
segfault(exit 139)로 끝나 결과 파일이 없었다. 로봇 동작과 무관한 시뮬레이터 실패로 보고 같은 조건으로
한 번 다시 돌린 결과를 셌다(첫 시도 폴더는 `seed_*_crash_1`). 두 번째 시도는 둘 다 완주했다.
크래시를 실패로 세면 완주율은 23/40 이다.

## 읽는 법

- 실행 단계는 계획이 나온 경우 26 개 중 25 개를 끝냈다. **완주율을 끌어내리는 것은 계획이다** —
  실패 15 건 중 14 건이 계획 단계, 그중 9 건이 복귀다.
- 40 개로는 구간이 넓다(−15.5 %p·+13.3 %p). 복귀 계획을 고친 뒤 비교하려면 같은 40 seed 를 다시 돌리면 된다.

## 영상 확인 (같은 날 밤)

seed 6965·2112·7648 을 같은 스냅숏·같은 인자에 `--video` 만 더해 다시 돌렸다(작업 488,
`artifacts/20260927_factory_random40_video/`). 세 seed 모두 영상 없이 돌린 결과와 같았다 — 6965 는 같은
전환점에서 `pos=0.0300,yaw=-0.0510` 으로 실패, 2112 는 244.4 s·복귀 6.6 mm·하역 7.0 mm, 7648 은 169.8 s·
복귀 6.5 mm·하역 2.6 mm. 이 세 seed 에서는 렌더링이 결과를 바꾸지 않았다.

## 이 기록이 말하지 않는 것

- 인식 기반 임무(`--use-perception`)·8 km/h 설정의 성공률.
- 실물 차체·센서 성능. 삽입 오차 7.7 mm 는 합성 추종기의 종점 오차다.
- 영상을 켠 실행과의 동일성(확인한 3 seed 밖). 영상 표시(인셋)만 다른 두 판에서 궤적이 갈린 사례가
  있었고 이유는 규명되지 않았다(2026-09-23 기록).
