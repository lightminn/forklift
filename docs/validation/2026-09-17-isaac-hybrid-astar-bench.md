# Hybrid A* 기록 버그 수정과 대규모 검증 제출

## 확인된 수정

이전 84초 녹화 중단은 기어 전환 후 `segment_index`에 들어간 NumPy
`int64`를 JSON으로 저장하지 못한 문제였다. 예외 결과 저장도 같은 값으로
실패했고, 이어 Isaac 종료 과정에서 segfault가 났다. 실제 기어 전환을
거치는 회귀시험으로 재현했다. 경로 구간 번호를 Python `int`로 유지하고,
시뮬레이터 기록 인코더도 NumPy 수치·배열을 수치형 JSON으로 변환한다.

기존 속도 재실행과 속도 증가 재실행 모두 집기·운반·하차·포크 이탈을
완료했다. 같은 seed 0과 같은 장애물·목표 배치로 비교했다.

| 설정 | 접근 / 운반 속도 | 시뮬레이션 작업 시간 | 목적지 중심 오차 |
|---|---|---:|---:|
| 기존, bench01 | 0.14 / 0.12 m/s | 103.758 s | 5.229 mm |
| 증가, bench02 | 0.35 / 0.30 m/s | 62.475 s | 1.784 mm |

작업 시간은 약 40% 감소했다. 삽입 속도는 0.055 m/s로 유지했다.
구동·조향 설정은 합성 값이고, 실물 하드웨어 성능 검증이 아니다.

## 추가 검사와 소규모 결과

- 실제 팔레트 위치·yaw로 장애물 겹침을 매 physics step 확인한다.
- 조향 바퀴의 외곽을 포함하도록 비적재 반폭을 0.36 m로 잡았다.
- 삽입과 낮춘 포크 이탈 중에는 URDF의 포크 4개 박스와 팔레트 22개
  박스 사이의 3차원 SAT 검사를 수행한다. 실제 base/pallet quaternion과
  측정 lift를 사용하며 2 mm 여유를 요구한다. 순간 기하 검사이며
  PhysX 접촉력 측정 또는 연속 구간의 접촉 부재 증명은 아니다.
- 0.30/0.35 m/s, 구동·조향 지연 100 ms의 추종 회귀시험을 추가했다.

bench03의 고정 seed [0, 7, 17, 42, 1, 12]에서 17·42·12는 완료했고,
7·1은 접근 경로 검색 실패로 주행 전에 정지했다. seed 0은 새 카메라
타임스탬프 단조 증가 assertion 때문에 중단됐다. 설치된 Isaac Camera
소스에서 `get_rgba()`가 RGB annotator를 직접 읽는 반면 `get_current_frame()`
메타데이터는 캐시됨을 확인해, 해당 메타데이터를 주행 중단 조건에서
제외하고 감사 기록으로만 유지했다. 이후 대규모 작업의 첫 seed 0은
삽입 검사와 영상 녹화를 포함해 62.475초, 1.784 mm 오차로 완료했다.

## 대규모 작업 — 실행 중

사용자가 대규모 검증 제출을 요청해 다음 작업을 제출했고 RUNNING을
확인했다. 완료 결과로 읽으면 안 된다. 요청 seed는 성공 여부로 바꾸거나
생략하지 않으며 설정과 코드는 작업별 snapshot으로 고정했다.

| 작업 | Slurm ID | seed | 범위 |
|---|---:|---|---|
| 물리 시뮬레이션 | 1025 | 0–99 | 매 seed 새 Isaac 프로세스, 장애물 4개, 전체 운반 단계 |
| 경로 계획 | 1026 | 0–999 | 실제 공식 물품 에셋 크기, Hybrid A*, 최대 30,000 확장 |

기록 식별자: `artifacts/20260917T121923Z_large_transport/`.
접속·보관 위치·확인 항목은 해당 디렉터리의 `jobs.json`에 있다.
물리 작업은 `benchmark.json`을 매 seed 갱신하고, 계획 작업은
`progress.json`과 `results.json`을 원자적으로 저장한다. 물리 작업의
Slurm 비정상 종료코드는 시나리오 실패가 하나라도 있을 때도 발생하므로
100개 결과가 모두 기록됐는지와 개별 실패 원인을 함께 확인해야 한다.

계획만 수행한 선행 20개 seed에서는 13개 성공, 7개 검색 실패였다.
실패 seed도 원본 기록에 남아 있다. 검색 실패는 물리적으로 불가능하다는
증명이 아니다. 바퀴 폭 확대 전 seed 7 성공을 가정했던 단위시험은 갱신해
seed 7의 실패 시 실행 가능한 부분 경로가 노출되지 않는지 검사한다.
