## 2. 결과

- **안전:** B 의 틀린 확정은 0 이다. 불채택 조건(하나라도 틀린 확정)에 걸리지 않는다.

## 3. 판정에서 따로 다룬 것

- **val4_092:** Isaac 기동 중 멈춰(`stall.jsonl`) 러너가 위치 추정에 들어가지 못했다. `start_reloc` 기록이 없다. `reloc_judge` 는 이 세션을 유효로 셈하고 성공이 아니다. 비교 도구는 처음에 이 세션을 '이동 켬 기록 없음'으로 보고 멈췄다. 정적 단계가 없으면 A 와 B 모두 실패로 같으므로, 도구를 고쳐 그런 세션을 양쪽 실패로 세고 목록(`no_reloc`)에 남기게 했다(7bfa1652). 판정 기준이나 다른 세션의 분류는 바뀌지 않는다. 기록이 있는데 이동 켬 기록만 빠진 세션은 지금도 도구가 멈춘다.
- **bundle rc≠0 24:** 운용자 요청으로 끝난 세션의 종료 코드다. 판정은 기록에서 한다.

## 4. 해석과 한계

- 0.3 m 앞뒤 이동은 이 홀의 정적 실패를 2/16 구제했고, 틀린 확정은 늘리지 않았다. 대신 실패 세션마다 약 20 s 를 더 쓴다. 남쪽 반복 선반 칸의 모호성은 대부분 0.3 m 로 풀리지 않는다.
- 같은 홀, seed 5 배치 하나의 조건부 결과다. 출발 사이의 공간 상관 때문에 실제 표본은 84 보다 작을 수 있다.
- 통로 검사는 정적 시뮬 장면용이다. 이동 중 정지 장치가 없으므로 실차·콘솔 경로로 옮기려면 장애물 층과 현장 정지가 따로 필요하다(계획 1·4 절).
- 옵션은 기본 끔으로 남긴다. 런처 기본 승격 여부는 총괄이 정한다.
