## 읽는 법

- **형식 경로는 통과했다.** 열 변환, 스트림별 순서, 32 bit 되감김 한 번 넘김(두 스트림 모두 같은 자리에서), 연속 구간 하나, 결측 0. 장치 시각에 역행·중복이 없어 `clean_points` 가 버린 점도 없다.
- 두 스트림의 drift 가 소수 다섯째 자리까지 같다 — 자이로와 가속도가 같은 장치 시계를 쓴다는 설계 판단(Codex 검토도 같은 판단)과 맞는다.
- 자이로 최대 간격 4,990 µs 는 표본 하나 빠짐이다. 가속도는 최소 간격이 2,493 µs(자이로 주기)인 곳과 최대 24,925 µs(약 다섯 표본 빠짐)인 곳이 있다 — 가속도 표본이 고르게 오지 않는다. 실차 기록의 footer `max_gap_us` 로 같은 것을 본다.
- **drift −85 ppm 과 잔차는 벽시계(`time.time()`)에 대한 값이다.** 기록 중 NTP 가 벽시계를 고칠 수 있으므로(반쪽 차 3.4 ppm 이 그 몫일 수 있다), 이 수치는 장치 시계와 호스트 단조 시계의 관계를 말하지 않고 M3 지연 정확도의 증거도 아니다. 잔차 p50 7 ms 도 10-23 기록기가 Python 콜백에서 잠금을 잡고 `time.time()` 을 읽은 시각의 변동이다. 단조 시각의 값은 G2 도구로 새로 기록해서 얻는다.
- 이 장치의 내장 IMU 보정 계수는 단위행렬·편향 0 이다(10-23 `meta.json`). 공장 IMU 보정이 없는 장치라 motion correction 을 켜도 바뀌는 것이 없다 — 편향은 G3 정지 구간에서, 배율은 G9 로 확인한다.
