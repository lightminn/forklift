### 관측 결과가 G5 와 다른 이유

- 관측된 재현성: G2 재실행과 G2′ 는 공통 시도 10 쌍 모두 도착 자세가 같고 깊이 해시도 같았다. 이번 실행에서도 전환점이 없는 관측 구간을
  지난 1020 후보 2 는 도착 자세가 비트 단위로 같고 깊이 해시도 같다. 이 조건에서 렌더가 재현된다는 증거이고, 렌더러 전반의 결정성을 증명하지는 않는다.
- 나머지 공통 시도 43 쌍은 깊이 해시가 다르다. 도착 자세(`arrived_pose`)의 평면 거리 차는 중앙값 0.32 mm·yaw 0.45 mrad, 최대 33.5 mm·
  27.4 mrad(1001 후보 2, 판정은 같음)다. P2 가 관측 구간의 전환점 정지도 바꾸기 때문이다(계획 P2 절: 모든 단계 추종기에 0.008).
- **검출 판정이 바뀐 시도 6 개**: 좋아진 쪽 4(1002·1005 후보 1 no_pallet → valid, 도착 차 0.070 mm·0.11 mrad; 1017 후보 1 no_pallet → valid;
  1023 후보 0 invalid → valid), 나빠진 쪽 2(seed 1 후보 4 valid → invalid, 9.5 mm·10.6 mrad; 1001 후보 1 invalid → no_pallet).
  0.07 mm 수준의 입력 차이로 판정이 뒤집힌다는 것은 관측 사실이다. 원인이 RANSAC 표본·평면 순서인지는 분리하지 않았다(가설).
  이 판정 변화는 P2 → 도착 자세 → 깊이 입력을 거친 **변경의 간접 효과이며, 방향은 우연**이다. 검출기가 나아졌다는 증거는 아니다.

### 해석의 한계

seed 마다 결과 하나를 메커니즘 하나에 돌리는 것은 하류 경로가 G5 와 같음을 확인한 경우(1011)나 실패했던 탐색 단계가 그대로 재현된
경우(1020·1029)에만 가능하다. 나머지는 도착 자세 → 깊이 → 검출 추정 → 계획 목표 → 탐색 결과가 연쇄로 바뀌었다. 계획에 적은 G5 seed 기준
기대치 26/30 은 **사전 예상**이며, "검출 판정 변화가 없었다면" 의 반사실 값을 이 자료로 계산할 수는 없다.

### 폴백과 계획 시간

- 폴백이 쓰인(간격 8 이 실패한) 탐색은 6 개 seed 에 있다. 성공한 3 개: 1020·1029 접근 간격 4, 1006 관측 구간 간격 2. 끝까지 실패한
  3 개: 1025 운반(간격 1 까지 `no_path`), seed 7 후보 3·1008 후보 4 의 관측 구간(간격 1 까지 `no_path`, G5·G2′ 에서도 실패한 후보라 결과는 같다).
- `planning_wall_s`: 1025 65.6 s, seed 7 50.2 s(G2′ 8.5 s), 1008 45.9 s(G5 6.6 s). 이전 실행(G2′·G5)의 최대는 10.5 s 였다. 폴백이 결과를
  바꾸지 않는 경우에도 **실패하는 탐색의 비용을 5–7 배 키운다**. 계획 중에는 시뮬레이션 시간이 진행하지 않는다.
- 관측 구간의 시도 내역은 `planning_traces` 가 아니라 `paths.observe.search_attempts`(선택된 후보)와 `observation_candidates[].analytic_expansion_interval`
  에 남는다.
